# EVT-20261113-000513 广东建设现代化产业体系

## Event Overview

2026年11月13日，《人民日报》理论版（第09版）刊发了题为《奋力建设更具国际竞争力的现代化产业体系（调查与思考）》的文章。该文章由广东省习近平新时代中国特色社会主义思想研究中心的顾乃华执笔，旨在总结广东在推动先进制造业与现代服务业深度融合方面的实践经验，并为“十五五”时期建设现代化产业体系提供政策启示。

事件背景源于习近平总书记对广东发展的多次重要指示，强调广东要“始终坚持以制造业立省”，“加快建设以实体经济为支撑的现代化产业体系”。文章回顾了改革开放以来广东制造业的发展历程，分析了2025年广东经济结构数据，并归纳了广东在政策协同、高水平对外开放、区域联动及平台支撑等方面的具体做法。

## Core Facts

**1. 政策指引与战略定位**
*   **根本遵循**：习近平总书记指出，中国式现代化不能走脱实向虚的路子，必须加快建设以实体经济为支撑的现代化产业体系；要求广东“加快产业转型升级，推进产业基础高级化、产业链现代化，发展战略性新兴产业，建设更具国际竞争力的现代化产业体系” [Article #388]。
*   **战略目标**：推动先进制造业和现代服务业深度融合发展，是顺应新一轮科技革命和产业变革趋势，增强制造业核心竞争力、建设现代化产业体系的重要途径 [Article #388]。

**2. 广东经济产业结构现状（2025年数据）**
*   **总体规模**：2025年，广东经济总量达14.58万亿元，连续37年居全国首位 [Article #388]。
*   **制造业基础**：“十四五”时期，全省规模以上工业企业数量较5年前增长超四成，累计培育8个国家先进制造业集群 [Article #388]。2025年，广东先进制造业、高技术制造业增加值占规模以上工业增加值比重分别达56.2%、34.7% [Article #388]。
*   **服务业结构**：2025年，广东服务业增加值8.5万亿元，占全省经济总量比重为58.3% [Article #388]。其中，现代服务业增加值占服务业增加值比重达64.9% [Article #388]。
*   **数字经济与新兴产业**：截至2025年底，广东数字经济规模、工业机器人产量、服务机器人产量均位列全国第一 [Article #388]。文化及相关产业增加值稳居全国首位 [Article #388]。

**3. 融合发展的核心机制**
*   **双轮驱动**：以先进制造业高质量发展筑牢现代化产业体系根基，以现代服务业高质量发展推动现代化产业体系向新、向优、向智、向绿迈进 [Article #388]。
*   **数字赋能**：以数字技术强大的跨界渗透力，推动先进制造业与现代服务业协同共生、深度融合，带动制造业服务化和服务业制造化双向拓展 [Article #388]。
*   **模式创新**：形成从龙头骨干企业和中小企业“单点突破”到产业链供应链整体“链式改造”的实践模式 [Article #388]。

**4. 广东先行先试的经验做法**
*   **政策协同**：连续4年召开全省高质量发展大会，主题层层递进（从“再造一个新广东”到“制造业与服务业协同发展”） [Article #388]。出台《广东省制造业高质量发展促进条例》等多份文件，并将“促进制造业与生产性服务业深度融合发展”纳入广东“十五五”规划纲要 [Article #388]。
*   **制度创新**：开展注册资本认缴登记制度改革试点，实现企业开办“一天办结”；推出“信用+监管”分级分类管理；发布全国首个企业信用风险分类管理省级地方标准 [Article #388]。
*   **金融与人才支持**：推出“粤质贷”“星火贷”等金融产品，发挥战略性新兴产业投资引导基金作用；推广“订单式”人才培养模式 [Article #388]。
*   **高水平对外开放**：在自贸试验区率先实施跨境服务贸易负面清单；粤港海关推动“汽车出口快线”；粤港澳三地实施冷链物流湾区标准 [Article #388]。试点港澳工程专业人才职称评价，截至2026年5月底，共619名港澳专业人才取得内地职称 [Article #388]。
*   **区域联动**：依托港珠澳大桥、深中通道等基础设施，推进粤港澳大湾区国际科技创新中心建设，“深圳—香港—广州”创新集群跃居全球创新集群首位 [Article #388]。实施“百千万工程”，布局市级产业转移合作园区 [Article #388]。
*   **平台支撑**：构建国家级、行业、区域联动的工业互联网平台矩阵；布局中试平台、概念验证中心；上线“先用后转”服务平台；整合海外法务、物流、金融资源的粤企出海综合服务港 [Article #388]。

**5. 有益启示（针对“十五五”时期）**
*   **完善政策支持体系**：研究出台系统集成“政策包”，推动制造业转型升级政策和服务业扩能提质政策有机衔接 [Article #388]。
*   **融入全球价值链体系**：深化外商投资促进体制机制改革，支持制造业企业联合生产性服务企业抱团出海，打造链式出海模式 [Article #388]。
*   **立足资源禀赋**：推行“链长制”，梳理20条重点产业链，绘制动态更新产业链图谱，针对卡脖子环节实施“揭榜挂帅” [Article #388]。
*   **营造高效产业生态**：拓展工业互联网平台应用广度深度，打造高能级创新平台与服务载体 [Article #388]。
