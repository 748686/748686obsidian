# 首都高校新生同上“强国复兴有我”大思政课

## Event Overview

2026年11月12日，由北京市委教育科技人才工作领导小组主办的“强国复兴有我”2026年首都高校新生教育主题大思政课在清华大学新清华学堂举行。课程面向首都高校新生，旨在引导青年学生树立科技报国远大志向，积极投身教育强国、科技强国、人才强国建设。中央宣传部、教育部、科技部、中国科协、中国科学院及北京市委、市政府有关负责同志与1300余名学生共同参课。

## Core Facts

- **时间**：2026年11月12日
- **地点**：清华大学新清华学堂（北京）
- **主办单位**：北京市委教育科技人才工作领导小组
- **参与对象**：首都高校新生，共计1300余名学生
- **出席领导**：中央宣传部、教育部、科技部、中国科协、中国科学院和北京市委、市政府有关负责同志
- **课程形式**：打破传统课堂边界，采用“科技+艺术”表现形式，包括情景剧、舞蹈、诗歌合唱等多元舞台载体，全景式呈现我国科技事业的壮阔历程
- **课程环节**：
  1. 短片《点名》开篇，记录当代青年向祖国报到的决心
  2. 情景剧《种子》：运用情景演绎和人工智能数字重构，展现科技报国理想
  3. 情景话剧《马兰花开》：以“两弹元勋”邓稼先为原型，讴歌老一辈科研工作者无私奉献精神
  4. 情景剧《星辰》：展现科研工作者推动高水平科技自立自强的使命担当
- **配套活动**：设置“四个中心”大思政课主题展览
- **新闻报道**：2026年11月13日《人民日报》第04版要闻报道，记者潘俊强
