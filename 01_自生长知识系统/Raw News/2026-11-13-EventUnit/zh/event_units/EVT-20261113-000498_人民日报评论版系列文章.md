# Event Name
人民日报评论版及要闻版系列文章（2026年11月13日）

## Event Overview
2026年11月13日，《人民日报》第05版（评论版）和第06版（要闻版）刊发了一系列重要文章。内容涵盖人工智能时代技能人才的重新定义与培养、红色革命精神与为民造福宗旨的当代实践、民族地区科学教育赋能，以及党和国家监督体系的完善等主题。其中，第06版刊载了李鸿忠撰写的理论文章，学习贯彻党的二十届五中全会精神。

## Core Facts
1. **技能人才与AI时代**：《人民日报》评论版刊发《人工智能时代，技能人才何为》，中国人民大学劳动人事学院院长赵忠接受对话时表示，技能正从“手”的延伸走向“脑”的延展，具备判断、管理、协调、合作能力愈发重要。技术进步既造成部分技能过时，也催生新技能，二者并不矛盾。建议通过教育和技能提升形成与AI的互补共生关系，并探索建立数字资产收益分享机制。
2. **南梁精神与为民造福**：评论员王锦涛撰文《为民造福是永远的落脚点》，结合甘肃庆阳南梁革命根据地的历史与现实，强调中国共产党人“面向群众”的初心。文章指出庆阳已建成国家“东数西算”枢纽节点之一，承接全国1/4智算需求，带动就业55万人。
3. **科学教育与东西部协作**：王禹舜撰文《让科学种子在追问中萌发》，讲述浙江省杭州市上城区对口支援四川省甘孜藏族自治州雅江县的经历，通过建设智慧教室、邀请科普资源、举办创新创业大赛等方式激发高原青少年好奇心。
4. **财税政策调整**：评论版刊发《政策更精准，发展增实效》，解读财政部、税务总局公告，明确自2027年4月1日起，新能源汽车增值税出口退税率由13%下调至9%，旨在引导企业依靠技术品质拓展市场。
5. **完善党和国家监督体系**：第06版刊发李鸿忠撰写的长篇理论文章《进一步完善党和国家监督体系》，学习贯彻党的二十届五中全会精神。文章强调监督是治理的内在要素，是党在长期执政条件下实现“四个自我”的重要制度保障，并部署了推进政治监督具体化、做实党委全面监督、完善纪检监察双重领导体制等七项任务。
