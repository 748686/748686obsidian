# 习近平主席对美国进行国事访问及中美外交互动

## Event Overview

2026年9月24日至25日，中国国家主席习近平对美国进行国事访问。这是习近平应美国总统特朗普邀请进行的访问。访问期间，特朗普在白宫为习近平举行欢迎仪式，两国元首随后举行会谈。双方就构建中美建设性战略稳定关系、加强沟通与合作、管控人工智能风险以及促进人文交流等议题深入交换意见，旨在推动中美关系行稳致远。

## Core Facts

- **时间**：当地时间2026年9月24日上午（报道发布于9月25日）。
- **地点**：美国华盛顿特区，白宫。
- **主要人物**：
    - 中方：国家主席习近平、夫人彭丽媛；随行人员包括蔡奇、王毅、何立峰等。
    - 美方：美国总统特朗普、夫人梅拉尼娅。
- **事件经过**：
    1.  **欢迎仪式**：特朗普总统和夫人梅拉尼娅在白宫下车处热情迎接习近平夫妇。随后两国元首夫妇合影，步入白宫并在贵宾簿上签名。在军乐团奏响两国国歌后，习近平和特朗普分别致辞。
    2.  **致辞内容**：
        - 习近平向美国人民致以问候，祝贺美国独立250周年。强调此次访美是为传承友谊、拓展合作、增进人民福祉。指出中美应加强沟通、真诚合作、和平共处，守住不冲突不对抗底线，跨越“修昔底德陷阱”。提出未来5年中方将邀请10万名美国青少年赴华交流学习。宣布大熊猫“平平”“福双”即将落户亚特兰大动物园。
        - 特朗普欢迎习近平进行历史性国事访问，表示双方已建立伟大友谊。指出此访正值美国独立250周年，期待就贸易、安全、人工智能、科技等议题进行深入讨论，为世界和平与繁荣奠定基础。回顾二战同盟历史及飞虎队故事。
    3.  **后续活动**：欢迎仪式后，两国元首夫妇观看海军陆战队表演，检阅仪仗队，战机飞越白宫致敬。随后移步椭圆形办公室进行亲切友好交流。
- **核心共识/倡议**：
    - 双方一致同意构建中美建设性战略稳定关系（注：报道提及特朗普今年访华期间已达成一致，此次访问旨在引领关系行稳致远）。
    - 强调中美作为人工智能大国，有能力也有责任发展好、管控好人工智能，确保其受控于人、造福于民。
    - 重申合则两利、斗则俱伤，合作空间广阔。
