# Event Name
榆能集团开放合作服务一带一路

## Event Overview
2026年11月3日，《人民日报》第18版刊发专题报道（广告版），介绍陕西榆林能源集团有限公司（简称“榆能集团”）在共建“一带一路”框架下的开放合作实践。作为陕西省榆林市属重点国有企业，榆能集团自2012年成立以来已稳步成长为“中国企业500强”。报道指出，该集团立足陕北黄土高原，抢抓“一带一路”机遇，以通道联通、产业协同、绿色转型为路径，将业务从传统煤炭开采延伸至能化产品与低碳技术协同出海，并重点拓展中亚市场布局。

## Core Facts
1.  **企业定位与背景**：榆能集团是陕西省榆林市属重点国有企业，成立于2012年，扎根神府、榆神、榆横三大煤炭富集区，属于资源型地方国企。
2.  **物流网络建设（设施联通）**：
    *   **铁水联运**：控股建设并投运湖南华中铁水联运能源储配基地，衔接浩吉铁路与长江黄金水道，推动“北煤南运”及“疆煤入湘”，化工产品“进江达海”，辐射20余个省份。
    *   **沿海与出海通道**：借力秦皇岛港、黄骅港等沿海港口，将榆林优质动力煤运往国内沿海及韩国等地。
    *   **中欧班列**：以“榆西欧”中欧班列为牵引，经西安港“长安号”将聚氯乙烯、兰炭、金属镁等产品运往欧亚地区。
3.  **国际合作平台**：利用丝绸之路国际博览会（第十届）、中国国际矿业大会、榆林国际煤炭暨高端能源化工博览会、德国杜塞尔多夫国际铝工业展览会等平台开展技术交流与商务对接。
4.  **中亚布局进展（2026年关键节点）**：
    *   **4月**：随中国产业海外发展协会代表团赴土库曼斯坦阿什哈巴德，出席首届土库曼斯坦—中国商务论坛暨展览会，与土库曼斯坦财政与经济部、环境保护部就天然气化工、开采及光伏领域交流。
    *   **5月**：乌兹别克斯坦卡拉卡尔帕克斯坦共和国代表团访榆，调研零碳能源模式，商定搭建常态化交流平台。
    *   **9月**：随陕西代表团赴乌兹别克斯坦努库斯出席地区间经贸活动，与当地投资、工业和贸易部对接。
    *   **10月**：成立面向中亚的专业投资专班，推进市场调研、投资测算和项目台账。
5.  **特色产品出海（金属镁）**：
    *   旗下榆镁集团在荷兰鹿特丹等地布局海外仓，形成“国内生产—跨境运输—海外仓储—就近分销”体系。
    *   2021年4月，榆林首列金属镁出口铁路集装箱专列发车，原镁经天津分拨至加拿大、荷兰等地。
    *   业务正从单一贸易向合金研发、精深加工及镁基新材料延伸。
6.  **绿色低碳技术输出**：
    *   **煤炭开采**：郭家滩煤矿采用“保水采煤”技术。
    *   **电力**：横山煤电一体化项目拥有世界首台商业运行“三塔合一”间接空冷百万千瓦级机组；杨伙盘煤电一体化电厂落地全球首例自然通风直接空冷系统，入选国家首台（套）重大技术装备。
    *   **化工新材料**：总投资超100亿元的环氧树脂一体化项目，实现“煤炭—甲醇—丙烯—环氧树脂”产业链串联；氯丙烯直接氧化制环氧氯丙烷技术为国内首次工业化示范。
    *   **新能源**：加快布局风光新能源，构建风光火储一体化综合能源基地。
