# 日本民众抗议政府调整核政策

## Event Overview

2026年11月3日，据新华社东京电报道，近万名日本民众在东京国会议事堂正门前举行集会，抗议高市早苗政府谋求调整核政策及相关扩军动向。抗议活动主要针对近期日本政府高层关于引进核潜艇的言论以及可能修订“安保三文件”中“无核三原则”表述的动向。

## Core Facts

- **时间**：日前（报道发布于2026年11月3日）。
- **地点**：日本东京，国会议事堂正门前。
- **参与规模**：近万名民众。
- **主要诉求**：抗议高市政府调整核政策及扩军动向。
- **政府相关动向**：
    - 防卫大臣小泉进次郎多次公开表示，在讨论引进核潜艇问题时“不排除任何选项”。
    - 首相高市早苗本月在国会表示，将就自卫队引进核潜艇展开“具体且现实的讨论”。
    - 日媒报道称，高市政府或在年底修订“安保三文件”时，调整其中有关“无核三原则”的政策表述。
- **抗议者观点**：
    - 演讲者指出，高市政府推进军事化加剧了与周边国家的紧张关系，令其他国家“感到强烈的危机感”。
    - 抗议者吉川认为，日本增强军事力量的趋势“太过头”，若军事发展超出自卫所需甚至挑衅他国，则“极不正常”。
    - 抗议者红林美鹤表示，在民众生活负担加重的情况下，政府试图让核武器进入日本并修改宪法以重新成为能发动战争的国家，“绝不能被容许”。
