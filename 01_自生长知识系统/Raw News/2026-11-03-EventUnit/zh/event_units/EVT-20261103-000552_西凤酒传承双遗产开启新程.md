# EVT-20261103-000552：西凤酒“双遗产”保护与品牌出海进展

## Event Overview
2026年11月3日，人民日报第19版刊登由陕西西凤酒厂集团有限公司提供的数据及宣传内容，题为《传承“双遗产”文脉 开启凤香新程》。该事件主要围绕西凤酒在“十五五”开局之年，如何响应国家文化遗产保护规划，通过协同保护非物质文化遗产与工业遗产（即“双遗产”），并推动品牌国际化（“出海”）来守护三千年酿酒文脉。

## Core Facts
根据 source article #420 内容，核心事实如下：

1.  **政策背景**：2026年是我国“十五五”规划开局之年，我国首次在文化遗产保护领域制定五年规划——《文化遗产保护传承“十五五”规划》。该规划明确“坚持保护第一、合理利用和最小干预原则”，并提出“构建文化遗产大保护格局”、“推动物质文化遗产和非物质文化遗产协同保护”。
2.  **“双遗产”认定**：
    *   2021年，“西凤酒酿造技艺”入选第五批国家级非物质文化遗产代表性项目名录。
    *   2021年，“西凤酒厂”入选第五批国家工业遗产名单。
    *   西凤酒致力于推动这两类遗产的协同保护，守护其“三千年无断代传承的酿酒文化、酿造工艺”。
3.  **活态传承举措**：
    *   **博物馆**：2025年9月开馆的西凤酒文化博物馆，运用文物史料、实景复原与数字技术展示三千年酿造史。
    *   **酒海应用**：万吨酒海库中，秦岭荆条手工编织、内壁百层裱糊的古老酒海至今仍在实际应用，用于酒体陈化自然老熟。
    *   **工业旅游**：依托博物馆、酿造车间与酒海库，将工业旅游从单纯的“工厂参观”延伸为“文旅+工业”的体验式业态。
4.  **品牌出海现状**：
    *   西凤酒商标已在20个国家和地区成功注册。
    *   产品远销30多个国家和地区。
    *   已在东南亚、欧洲、非洲构建起销售网络。
