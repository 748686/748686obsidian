# 党的二十届五中全会公报及决议发布

## Event Overview

2026年10月29日下午，中国共产党第二十届中央委员会第五次全体会议（以下简称“党的二十届五中全会”）在北京闭幕。全会审议通过了《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》（以下简称《决定》）。

本次事件的核心内容包括：全会公报及《决定》的正式通过、《决定》起草过程及核心内容阐释、为学习贯彻会议精神而启动的中央宣讲团动员及辅导材料出版发行，以及向党外人士通报全会精神。

尽管首日提供的素材中混入了习近平会见阿曼苏丹海赛姆、习近平与秘鲁总统藤森庆子互致贺电、黄河保护治理工作指示、十四届全国人大常委会第二十五次会议等其他新闻（见来源交叉验证部分），但根据Global Merge Event Reason的判定，本文档聚焦于**党的二十届五中全会公报及决议发布**这一核心政治事件。

## Core Facts

1.  **会议时间与地点**：党的二十届五中全会于2026年10月29日在北京召开并闭幕（注：部分细节显示会议于10月26日开幕，会期两天半）。
2.  **核心成果**：全会正式通过《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》。
3.  **会议背景与意义**：
    *   会议召开于中国共产党成立105周年、“十五五”开局起步、基本实现社会主义现代化关键时期的节点。
    *   全会认为，《决定》是推进新时代党的建设新的伟大工程的纲领性文件，在党的历史上具有里程碑意义。
    *   会议指出，新时代全面从严治党开辟了百年大党自我革命新境界，党和人民赢得强党强国的历史主动。
4.  **《决定》主要内容**：
    *   **指导思想**：深入贯彻习近平党建思想。
    *   **重大判断**：分析了“三个更加艰巨”（维护国家主权安全发展利益任务、推动改革发展维护稳定任务、保持先进性和纯洁性任务）和“四大挑战”（执政能力、领导水平、队伍素质、拒腐防变）。
    *   **原则**：明确了持之以恒推进全面从严治党的7条原则，包括坚持服务使命任务、坚持以党的政治建设为统领、坚持全面从严、坚持问题导向、坚持守正创新、坚持以上率下、坚持依规治党。
    *   **部署**：对当前和今后一个时期管党治党、兴党强党作出战略部署。
5.  **学习宣传与贯彻**：
    *   **中央宣讲团动员会**：2026年11月2日，学习贯彻党的二十届五中全会精神中央宣讲团动员会在京召开，中共中央政治局常委、中央书记处书记蔡奇出席会议并讲话。
    *   **向党外人士通报**：2026年11月2日，受中共中央委托，中共中央政治局委员、中央统战部部长李干杰向党外人士通报中共二十届五中全会精神。
    *   **辅导材料出版**：中央有关部门组织编写了《〈中共中央关于持之以恒推进全面从严治党若干重大问题的决定〉辅导读本》（人民出版社出版）和《党的二十届五中全会〈决定〉学习辅导百问》（党建读物出版社、学习出版社出版）。
6.  **海外反响**：全会在海外华侨华人中引发热烈反响，普遍认为彰显了中国共产党自我革命的勇气和为国为民的担当。
