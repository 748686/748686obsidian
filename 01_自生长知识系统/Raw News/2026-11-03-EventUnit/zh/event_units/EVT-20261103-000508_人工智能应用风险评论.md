# EVT-20261103-000508 人工智能应用风险评论

## Event Overview

2026年11月3日，人民日报发表题为《“过来人”与“窃脸人”（人民锐评）》的评论文章。文章通过对比AI技术在文化遗产复原（生成古人面孔）与身份欺诈（利用AI突破人脸识别）两个极端场景中的应用，探讨了生成式人工智能在赋能社会的同时所伴生的隐私泄露、伦理失范及安全风险。该评论引用了中国古代驯马智慧，提出以“相马、调声、辨疾”为喻，分别对应善识AI、善用AI和善管AI的治理路径，主张在坚持“以人为本”的前提下，通过明确法律红线与伦理底线来规避风险，确保技术向善。

## Core Facts

1.  **社会现象**：近期歌曲《过来人》走红，其特色是利用AI技术生成带有喜怒哀乐表情的古人“AI脸”，引发网友共鸣。
2.  **负面案例**：两名不法分子利用他人照片生成AI视频，成功突破购物平台的人脸识别系统，盗取账户信息。
3.  **风险警示**：评论指出，从“过来人”到“窃脸人”的转变反映了AI带来的隐私侵权风险。有公众担忧未来可能需“戴面具出门”以保护隐私。
4.  **延伸乱象**：除隐私和诈骗风险外，还存在将写稿答题全盘委托给AI、沉迷劣质AI短剧、以及通过伪造换脸和语音克隆实施诈骗等现象。
5.  **核心质疑**：AI究竟是赋能千行百业的利器，还是消解人的主体性、滋生各类风险的源头？
6.  **治理建议**：文章借用汉武帝时期驯服汗血宝马的“相马、调声、辨疾”三条经验，提出应对AI的三重策略：
    *   **相马（善识）**：辨识技术优劣，坚持“以人为本”，防止AI弱化人的思考、增强社会惰性、冲淡责任意识。
    *   **调声（善用）**：将安全、公平、向善理念嵌入研发，旨在提升效率便利，增强人的轻松感与幸福感，而非加剧焦虑。
    *   **辨疾（善管）**：增强风险意识，明确法律红线与伦理底线，厘清人与工具边界，从源头规避造假侵权风险。
