# 刀马旦直播传承戏曲

## Event Overview

2026年11月3日，《人民日报》刊登题为《心中常怀热爱，何处不是舞台（为梦想奔跑）》的报道，讲述了河北省保定市曲阳县55岁戏曲演员甄淑梭的从艺经历。报道指出，甄淑梭从乡村戏台走向网络直播间，通过短视频平台展示刀马旦技艺，吸引了大量年轻观众，实现了传统戏曲在数字时代的传承与创新。

## Core Facts

- **人物**：甄淑梭，55岁，河北省保定市曲阳县马羊村人，戏曲演员，工刀马旦。
- **起步**：13岁开始戏曲生涯，为学戏步行20多公里去戏校；条件艰苦（稻草为床、球鞋穿整个冬天），但坚持苦练。
- **早期演艺**：考入河北唐县梆子剧团，近10年间主要在乡村戏台跑龙套，珍惜每次登台机会。
- **南漂温州**：1994年与丈夫赴浙江温州演出，初时因不适应导致演出失误，后在同行鼓励下刻苦练习，半个月后成功站稳舞台，凭借“靠旗挑枪”“靠旗转刀”等高难度绝技成名，巅峰时期月演60余场。
- **直播转型**：2020年回到曲阳老家，在儿子建议下开始直播练功。初期担忧无人观看，但直播第七天即有超1万人在线观看。
- **传播效果**：账号“甄妮刀马旦”出圈，耍刀视频播放量破千万，全网粉丝超300万，多条短视频点赞数十万。
- **现状与行动**：一边精进功底、探索短视频创新表达，一边进行公益演出并向孩童传授基本功，推动传统文化在乡村薪火相传。
