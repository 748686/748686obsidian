# 九一八事变95周年纪念活动

## Event Overview
2026年9月18日至19日，为纪念九一八事变发生95周年，中国多地举行了系列纪念活动。这些活动旨在铭记历史、缅怀先烈、珍爱和平。主要活动地点包括北京、沈阳、黑龙江、南京及江西等地，参与人员涵盖高校师生、青少年代表、社会各界人士及志愿者等。活动期间，各地通过奏唱国歌、默哀、敬献花圈、主题展览参观及跨地域线上联动等多种形式开展爱国主义教育和国防教育。

## Core Facts
*   **时间**：2026年9月18日（主要活动日期），报道发表于9月19日。
*   **核心主题**：九一八事变95周年纪念，主题为“缅怀先烈 珍爱和平”及“勿忘九一八”。
*   **参与主体**：包括中国人民抗日战争纪念馆、沈阳“九·一八”历史博物馆、侵华日军第七三一部队罪证陈列馆、侵华日军南京大屠杀遇难同胞纪念馆、新四军军部旧址陈列馆等机构；参与者包括高校师生、青少年代表、社会各界代表、共青团及退役军人事务部门负责同志。
*   **主要形式**：仪式教育（升旗、唱国歌、默哀、撞钟、献花）、实景研学（参观罪证陈列馆、展览）、线上联动直播、专题展览。
*   **关键数字**：
    *   北京抗战馆：近200人参与。
    *   黑龙江/哈尔滨青少年活动：400余人参加。
    *   江西新四军军部旧址活动：100余人参加。
    *   江西专题展：依托125张图片史料、25件（套）实物展品。

## Unique Information by Source
**ARTICLE #469 (People's Daily / 人民日报):**
*   **北京/沈阳联动细节**：9月18日上午9时18分，北京中国人民抗日战争纪念馆举行活动，近200人参与。同日，与沈阳“九·一八”历史博物馆进行跨地域联动直播，主题为“山河共鉴 抗战记忆”。
*   **黑龙江/哈尔滨细节**：在侵华日军第七三一部队罪证陈列馆举办省级示范活动，400余人参加。活动设“警钟长鸣·勿忘国耻”、“山河回响·缅怀忠魂”、“少年砥志·强国有我”三个篇章，包含国防教育和民族苦难历史实景研学。
*   **南京细节**：9月18日上午，社会各界代表在侵华日军南京大屠杀遇难同胞纪念馆撞响和平大钟。南京艺术学院大学生张博翔参与朗诵并发言。
*   **江西细节**：9月18日上午，100余人在江西南昌西湖区新四军军部旧址陈列馆园林广场默哀献花。同时举办“长征砺初心 红土育忠魂——江西大地走出的雨花英烈”专题展。
