# Event Name
西康高铁新建客站竣工验收

## Event Overview
2026年9月18日，连接陕西西安与安康的西康高铁项目中，位于商洛市及安康市境内的四座新建客运站——牛背梁站、柞水西站、镇安西站和安康西站——完成了竣工验收。根据《人民日报》报道，该高铁投运后，西安与安康两地的通行时间预计将从目前的约3小时缩短至1小时以内。

## Core Facts
- **事件时间**：2026年9月18日（竣工验收完成日）；报道日期为2026年9月19日。
- **事件地点**：陕西省西安市至安康市区间，具体涉及位于商洛市的牛背梁站、柞水西站、镇安西站以及安康市的安康西站。
- **涉及主体**：西康高铁项目。
- **关键进展**：四座新建客站完成竣工验收。
- **预期影响**：投运后，西安与安康两地通行时间由约3小时缩短至1小时以内。
