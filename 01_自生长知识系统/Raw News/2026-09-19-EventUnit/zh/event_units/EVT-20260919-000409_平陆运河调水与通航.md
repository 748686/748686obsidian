# Event Name
**平陆运河通航与新增调水工程（2026年9月）**

## Event Overview
2026年9月中旬，平陆运河正式通航。作为新中国成立以来建设的首条通江达海大运河，其通航运行依赖于广西“引郁入钦”调水工程的扩容。水利部门批复在原有设计最大调水流量（每秒20立方米）基础上，新增每秒4立方米的基础补水流量，以确保运河满足内河Ⅰ级航道标准及5000吨级船舶通行需求。该事件标志着西部陆海新通道骨干项目的投入运营，其核心技术在于通过创新省水船闸设计和流域水资源联合调度，解决钦州地区枯水期天然来水不足的问题，同时严格守住西江干流生态流量底线，避免对下游珠江三角洲用水和生态造成负面影响。

## Core Facts
*   **通航时间**：平陆运河于2026年9月近日实现通航。
*   **运河区位**：北起广西南宁平塘江口，跨越分水岭，经钦州灵山县，沿钦江干流进入北部湾。
*   **调水工程**：
    *   **既有工程**：“引郁入钦”调水工程，此前设计最大调水流量为每秒20立方米，主要服务于钦州沿海工业和城市供水。
    *   **新增流量**：为支持运河通航，新增基础补水流量每秒4立方米。
    *   **总需求**：运河近期航运用水需求约每秒24立方米。
*   **水文背景**：钦江年径流量约20.3亿立方米，但时空分布极不均衡（汛期占83%，枯水期仅占17%），且分水岭段无河流汇入，天然来水不足以支撑高等级航道。
*   **节水技术**：
    *   运河全线水位落差约65米，设马道、企石、青年三大梯级枢纽。
    *   马道、企石枢纽采用了全球规模最大的三级叠合式省水船闸。
    *   通过省水池技术，超过60%的调节用水实现循环利用。
    *   三大枢纽协同运行，年节水量超10亿立方米。
*   **调度保障**：依托郁江干流上梯级分布的多个大型水库（总调节库容数十亿立方米）进行联合调度，兼顾发电、航运、防洪及生态流量底线。

## Known Current Impact

*   **水资源分配**：建立了“引郁入钦”扩容后的联合调度体系，实现运河补水、城市供水、生态维持的多目标平衡。
*   **经济效益**：作为西部陆海新通道骨干，预计将显著降低西南地区通江达海的物流成本，促进沿线产业发展。

## Event Conclusion
平陆运河于2026年9月正式通航，标志着中国西南通江达海格局的重大突破。该事件的核心技术挑战在于如何在天然水资源分布不均的背景下，通过极小的增量调水（新增每秒4立方米）支撑高等级航道运营。通过对“引郁入钦”工程的扩容及全球最大规模省水船闸的应用，工程实现了水资源的高效循环利用与流域统筹调度。目前该事件处于单源官方权威报道阶段，缺乏多源独立数据交叉验证，但报道逻辑严密，清晰地展示了工程在解决航运用水、保障下游生态及提升区域防洪能力方面的综合效益。后续需关注实际运营数据与初期环境影响的监测反馈。
