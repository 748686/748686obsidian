# Event Name

贵州从江县“廖崩嗒佩”合唱团及其衍生文艺作品的创作与传播事件（2018-2026）

## Event Overview

本文档综合整理了2026年11月18日《人民日报》第13版（文化版）发布的两篇相关报道。事件核心围绕贵州省黔东南苗族侗族自治州从江县谷坪乡中心小学的一支苗族女孩合唱团——“廖崩嗒佩”（苗语意为“勇敢女孩”）。该合唱团因创作歌曲《大山的小孩》、登上“村BA”舞台以及改编电影《勇敢女孩合唱团》上映而受到关注。

两篇报道分别从新闻纪实和创作者感言的角度，记录了这一“新大众文艺”案例的形成过程：从乡村教师的初衷、志愿者团队的介入，到音乐创作、MV拍摄、小说编写及电影上映的完整链条。

## Core Facts

**1. 主体对象**
*   **地点**：贵州省黔东南苗族侗族自治州从江县谷坪乡中心小学。
*   **团体**：苗族女孩合唱团，名“廖崩嗒佩”（意为“勇敢女孩”）。
*   **核心歌曲**：《大山的小孩》。
*   **衍生作品**：
    *   小说：《廖崩嗒佩合唱团》（作者：肖勤）。
    *   电影：《勇敢女孩合唱团》（导演：邵兵，2026年10月上映）。
    *   MV：由贵州新文艺团队“饱饱盒子”制作。

**2. 关键时间节点与人物**
*   **2018年**：教师兰光庭发现当地孩子上学兴趣不高、性格内向，开始干预引导。
*   **2021年**：在校长王庆华支持下，正式组建“廖崩嗒佩”合唱团（初始32人），旨在通过唱歌培养孩子们的勇敢和自信。
*   **2022年**：学校教师通过社交平台联系音乐人张超；次年（报道语境为第二年，即2023年左右或时间线表述存在差异，需见下文冲突分析），张超团队邀约纪录片导演陈晓龙、作家肖勤、词作人玉镯儿等来到谷坪乡。
*   **歌曲创作**：孩子们通过卡片写下天马行空的想象（如“希望变成大树根”、“太阳和月亮是好朋友”），共同创作歌词，最终定名为《大山的小孩》。
*   **2023年7月底**：合唱团登上黔东南州台江县“村BA”赛场，迎来第一场正式演出。
*   **2026年10月**：电影《勇敢女孩合唱团》在全国院线上映。

**3. 主要人物及其角色**
*   **兰光庭**：谷坪乡中心小学语文教师，从大山走出的孩子，牵头创办社团，发起对外联系。
*   **王庆华**：谷坪乡中心小学校长，支持组建合唱团。
*   **滚乌甩**：合唱团领唱，电影人物原型之一，自信大方，梦想是回乡当教师。
*   **滚友克**：队员，电影人物原型之一，梦想是成为音乐人为山里孩子创作歌曲。
*   **肖勤**：贵州省文联副主席、省作协副主席，以合唱团为原型创作小说《廖崩嗒佩合唱团》，并参与歌曲词作创作。
*   **邵兵**：演员转导演，读后深受感动，执导电影《勇敢女孩合唱团》。
*   **张超**：音乐人，通过社交平台收到教师私信，邀请团队进山。
*   **陈晓龙**：纪录片导演，参与前期采风。
*   **玉镯儿**：词作人，参与歌曲创作。

## Known Current Impact

1.  **个人层面**：改变了合唱团女孩们的性格（从胆怯害羞到自信大方），并明确了她们未来的职业理想（回乡教书、创作音乐）。
2.  **社会层面**：形成了从一首歌、一支MV、一部小说到一部电影的完整文艺作品链条，成为“新大众文艺”的典型案例。
3.  **文化层面**：展示了乡村教育和艺术介入对留守儿童/山区儿童心理建设的积极影响，被《人民日报》作为文化版块的重点报道。
4.  **传播层面**：歌曲和合唱团的视频/演出在互联网上传播（“火爆全网”），提升了当地知名度。
