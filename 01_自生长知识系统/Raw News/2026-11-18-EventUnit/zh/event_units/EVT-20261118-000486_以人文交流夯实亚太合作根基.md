# 人民日报报道亚太经贸合作实效

## Event Overview

2026年11月18日，《人民日报》第四版发表题为《从车间到市集，亚太合作惠企利民》的报道。该文章系“亚太经合组织（APEC）‘中国年’”系列报道的一部分，旨在通过具体案例展现“开放、创新、合作”三大优先领域的落地成效。报道记者实地走访了浙江金华永康市、广东深圳罗湖区和江苏苏州姑苏区，分别从通关便利化、产业链协同和跨境支付互联互通三个维度，阐述了中国与亚太经济体经贸合作的微观成果。

## Core Facts

- **政策背景**：亚太经合组织（APEC）“中国年”确定“开放、创新、合作”为三大优先领域。
- **案例一：通关便利化（浙江金华）**
    - 浙江安德电器有限公司主营高端家用厨房电器，与澳大利亚、新加坡等15个APEC经济体有贸易往来。
    - 企业获得AEO（经认证的经营者）认证后，享受国际贸易“绿色通行证”待遇。相比常规企业，AEO企业平均查验率降低20%，进口平均通关时间缩短34%。
    - 2025年，该企业订单总额比上年增长约22%，对APEC经济体出口比上年增长9.6%。
    - 宏观数据：除巴布亚新几内亚以外的APEC经济体均已建立并实施AEO制度，中国海关已与其中10个实现互认。今年前7月，我国AEO企业与APEC经济体进出口总额达9.19万亿元，较去年同期增长21.87%。
- **案例二：产业协同与市场共享（广东深圳）**
    - 深圳市宏济医疗技术开发股份有限公司董事长胡济凡于2014年创业，依托粤港澳大湾区完整产业链（精密制造、电子信息、软件开发等）实现研发到产业化闭环。
    - 2025年，“亚太中小企业合作区·深圳市罗湖区”获工业和信息化部批准认定。
    - 合作区推出轮值服务月机制，由亚太各经济体商协会或官方代表按月轮值驻点，提供政策法规及营商环境咨询服务。
    - 近期到访该企业商谈合作的临床专家、合作伙伴中，一半以上来自亚太地区。
- **案例三：跨境支付互联互通（江苏苏州）**
    - 苏州姑苏区双塔市集等商圈已实现泰国电子钱包等境外支付方式直接扫码付款（泰铢扣款）。
    - 支付宝“外卡内绑”服务已支持7种国际主流银行卡；依托Alipay+跨境支付网络，18个国家和地区的90多款主流电子钱包、手机银行可在中国直接使用。
    - 苏州平江路、山塘街等升级为入境消费友好型商圈，拙政园、留园及周庄、同里等升级为入境消费友好型景区，2500多家热门商户设有便利支付标识。
    - 2025年，苏州通过上述两类便利服务完成的消费金额和笔数均比上年增长约75%。
    - 今年前三季度，全国范围内来自APEC经济体的入境游客通过这两类服务完成的交易金额同比增长56%。
