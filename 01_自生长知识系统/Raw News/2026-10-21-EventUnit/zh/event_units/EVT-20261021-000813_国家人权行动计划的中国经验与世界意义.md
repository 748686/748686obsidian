# 国家人权行动计划的中国经验与世界意义

## Event Overview

2026年10月21日，《人民日报》第13版（综合版）刊发由中南大学人权研究中心研究员黎娟撰写的文章《国家人权行动计划的中国经验及其世界意义》。文章结合2026年6月发布的《国家人权行动计划（2026—2030年）》（即中国第五期国家人权行动计划），总结了中国人权行动计划制定的连续性与稳定性，并探讨了其对全球人权治理的启示。文章提及在联合国人权理事会第六十三届会议期间，多位中外专家齐聚日内瓦，聚焦该主题进行深入探讨。

## Core Facts

根据来源文章，核心事实如下：

1.  **政策发布**：2026年6月，中国政府发布《国家人权行动计划（2026—2030年）》。这是中国政府制定和实施的第五期国家人权行动计划。
2.  **国际研讨**：在联合国人权理事会第六十三届会议期间，多位中外专家在日内瓦齐聚，聚焦中国第五期国家人权行动计划，探讨其中国经验及对全球人权治理的启示意义。
3.  **主要经验总结**：
    *   **以人为本、务求实效**：奉行以人民为中心的人权理念，坚持“人民幸福生活是最大的人权”，将生存权和发展权作为首要基本人权。聚焦脱贫攻坚、基础教育、医疗卫生、就业服务、社会保障等重点领域。
    *   **科学规划、行动导向**：立足经济社会发展实际，前瞻谋划，将宏观目标细化为可量化、可评估的具体任务指标。完善联席会议机制和第三方评估机制。
    *   **平等发展、普惠共享**：注重普遍保障中回应不同群体（少数民族、妇女、儿童、老年人、残疾人等）的差异化需求，保障各民族平等参与、平等发展的权利。
4.  **世界启示**：
    *   **行动重于承诺**：强调人权承诺需稳定、持续地转化为人权实效，中国的做法为全球人权治理提供了稀缺的制度产品（连续性与可预期性）。
    *   **实事求是**：坚持将人权普遍性原则同中国具体实际相结合，走出适合本国国情的人权发展道路。
    *   **公共产品**：批评部分国家充当“人权卫士”或通过对外战争、“颜色革命”等手段转移矛盾，指出中国的实践经验为广大发展中国家提供了借鉴，为全球人权治理贡献了公共产品。
5.  **作者信息**：文章作者为黎娟，身份标注为中南大学人权研究中心研究员。文章原刊于《人民日报》（2020年02月06日 01版）或相关版面，此次为2026年10月21日第13版的刊登。
