# Event Name

沙漠边上稻飘香：新疆和田县稻香村农文旅融合增收案例

## Event Overview

本事件单元记录了新疆和田地区和田县百和镇稻香村（原名阿亚格墩村）在“高标准农田建设”与“北京市援疆政策”双重推动下，从传统分散种植农业村向“稻田+”乡村旅游与田园综合体民俗文化村转型的过程。

根据《人民日报》2026年9月15日报道，该村通过1800亩集中连片规模化种植，将水稻亩产从约300公斤提升至600公斤左右，并打造出“金丝米”品牌。同时，通过发展庭院餐饮、稻香书院、热气球观光等文旅业态，实现了村民人均纯收入的显著增长。截至2025年，该村年接待游客约3.5万人次，成为沙漠边缘的乡村振兴典型。

## Core Facts

以下事实均基于来源文章 #518（《人民日报》2026-09-15）：

*   **地理与历史背景**：
    *   地点：新疆和田地区和田县百和镇稻香村（原阿亚格墩村，维吾尔语意为“最后一个沙包”）。
    *   环境：毗邻塔克拉玛干沙漠，曾受高沙丘包围，但依托喀拉喀什河和玉龙喀什河水源保留上百年水稻种植传统。
*   **农业改革**：
    *   模式：由分散种植转为由农业技术公司实施的规模化、集约化种植。
    *   规模：形成1800亩集中连片稻田。
    *   技术：良种选育与土壤改良。
    *   产量变化：水稻亩产从约300公斤提升至600公斤左右。
    *   品牌：形成“金丝米”品牌。
*   **经济与收入数据**：
    *   土地流转：租金每亩每年600元，较村民自主种植每亩年多赚约400元。
    *   集体增收：每年为村集体增收110多万元。
    *   村民收入：人均纯收入从改造前的9800元增至1.48万余元（增长约51%）。
*   **文旅发展**：
    *   启动时间：2021年，北京市援疆和田指挥部介入，提供资金与规划支持。
    *   定位：田园综合体民俗文化村。
    *   业态：餐饮（如大盘鸡）、庭院音乐会、稻香书院（公共文化空间）、热气球观光。
    *   游客流量：2025年接待游客约3.5万人次。

## Known Current Impact

基于来源 #518 的报道，当前已确认的影响包括：

1.  **经济增收**：

## Event Conclusion

本事件单元记录了新疆和田县稻香村在2021年至2026年间，通过**“高标准农田建设”**与**“农文旅融合”**双轮驱动实现的乡村振兴转型。

**核心结论：**
1.  **模式有效性**：在沙漠边缘的特定生态条件下，通过引入农业技术公司进行规模化种植（1800亩），结合对口援疆政策（北京）的文旅规划，成功实现了从“低产自给”到“高产品牌+旅游创收”的跨越。
2.  **数据支撑**：依据来源 #518，该模式带来了显著的经济回报（人均收入+51%）和社会效益（家门口就业、文化空间建设）。
3.  **局限性提醒**：该案例的成功高度依赖特定条件（充足水源、援疆资金、近5年的持续投入、特定客源市场）。来源明确指出其可复制性受限于水源、交通及客源市场条件。目前该信息仅由《人民日报》单一权威媒体来源支持，尚无独立第三方数据对其长期经济模型进行压力测试。
