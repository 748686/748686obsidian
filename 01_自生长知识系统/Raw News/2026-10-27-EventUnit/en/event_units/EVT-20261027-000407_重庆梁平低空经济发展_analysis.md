# 标题：人民日报报道中国乡村女性获联合国粮农组织表彰及澜湄青年体育交流活动

# 作者：人民日报（People's Daily）

# 标签：乡村振兴, 国际奖项, 联合国粮农组织, 女性赋能, 澜湄合作, 体育交流, 青年外交

# 一句话总结这篇文文章:
2026年10月27日《人民日报》报道了三名中国女性在国际农业发展基金（FAO）百年庆典上获得表彰，表彰她们在荒漠治理、农业机械化及非遗产业方面的贡献，同时报道了在昆明举行的第七届澜沧江-湄公河大学学生友好运动会圆满闭幕。

# 总结文章内容并写成摘要:
本文综合《人民日报》2026年10月27日的两则报道，核心内容分为两个独立板块：

第一板块聚焦“她力量”国际认可。在中国乡村振兴战略背景下，三位杰出女性代表殷玉珍、董敏芳、余锦秀在意大利罗马联合国粮农组织（FAO）总部举行的“百位巾帼英雄”颁奖仪式中获奖。该奖项从131个成员国的609名候选人中选出，中国入选人数居首。FAO总干事屈冬玉强调女性在粮食安全与自然资源管理中的不可替代作用。文章引用全联数据指出，截至2020年底，全国已有超500万贫困妇女通过产业发展脱贫，累计发放小额担保贷款及扶贫再贷款超4500亿元。

第二板块聚焦区域青年交流。第七届澜沧江-湄公河大学学生友好运动会在云南昆明落幕，来自13个国家20所大学的600多名运动员参与竞技，旨在通过体育促进澜湄流域国家间的友谊与文化交流。

**一、 联合国粮农组织（FAO）表彰中国乡村女性**
   1. **事件背景**
      - 时间地点：2026年10月，意大利罗马，FAO总部。
      - 活动名称：“FAO百年庆典农业粮食体系与乡村发展巾帼英雄”表彰活动。
      - 评选规模：来自131个成员国及地区的609名候选人，最终评选出100位获奖者。
      - 中国表现：3位女性获选，入选人数位居全球各国之首。
   
   2. **获奖代表人物及事迹**
      - **殷玉珍**：
        * 领域：荒漠化治理。
        * 事迹：40余年坚守毛乌素沙地，进行植树造林。
        * 评价：美国友人赛考斯（Scales）感其奉献精神而落泪。
      - **董敏芳**：
        * 领域：农业机械化与粮食生产。
        * 事迹：返乡投身家乡农业发展，推动农业生产机械化进程。
      - **余锦秀**：
        * 领域：非物质文化遗产（艾灸产业）。
        * 事迹：开发蕲春艾灸产业，培训艾灸从业者3万余人。

   3. **宏观数据与政策支撑**
      - **劳动力结构**：中国家庭农业经营者中，女性占比超过50%，平均工时高于男性。
      - **扶贫成效（截至2020年底）**：
        * 技能培训：1021万名贫困妇女及女性带头人接受技能培训。
        * 脱贫人数：500多万贫困妇女通过种植、养殖、手工业、电商等产业实现脱贫。
        * 金融支持：累计发放小额担保贷款及扶贫再贷款4500多亿元，支持870万妇女创业。
      - **政策框架**：《中国妇女发展纲要（2021—2030年）》明确实施农村妇女素质提高计划。

   4. **国际观点**
      - FAO总干事屈冬玉：女性是消除饥饿、自然资源可持续管理和农村韧性的关键力量。

**二、 第七届澜沧江-湄公河大学学生友好运动会**
   1. **事件概况**
      - 地点：云南省昆明市。
      - 主办/承办：昆明理工大学。
      - 时间：于2026年10月27日闭幕。
   
   2. **参与规模**
      - 参赛人数：600多名青年运动员。

      - 促进澜湄流域国家间的青年友好与文化交流。
