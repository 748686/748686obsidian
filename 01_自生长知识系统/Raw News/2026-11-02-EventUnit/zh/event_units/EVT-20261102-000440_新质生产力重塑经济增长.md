# Event Name

新质生产力重塑经济增长：自主可控技术底座下的人工智能规模化应用

## Event Overview

2026年11月2日，在《人民日报》第19版科技栏目刊发署名文章（作者为科大讯飞董事长刘庆峰），探讨在“十五五”开局之年，人工智能如何依托自主可控、安全可信的技术底座，跨越成本、场景和生态三道门槛，实现从“回答问题”到“执行任务”的深入应用，从而将技术能力转化为行业能力，真正形成新质生产力。文章核心观点在于：只有掌握关键核心技术，并在产品设计和业务流程中落实安全边界，人工智能才能稳定运行并实现规模化价值创造，最终解放人力、释放创造力。

## Core Facts

1.  **技术底座决定价值规模**：人工智能要实现规模化价值创造，必须建立在自主可控、安全可信的技术底座之上。系统稳定性、数据安全性、判断依据性及问题可追溯性是关键决定因素[370]。
2.  **自主可控解决主动权问题**：掌握关键核心技术是保障技术发展主动权的前提。关键在于芯片、框架、模型和应用的协同，确保大模型能够“训得出、用得稳、迭代快”[370]。
3.  **国内产业进展**：近年来，国内产业界持续推进软硬件协同创新，已实现基于国产算力的大模型全链路训练和推理，具备构建具有国际竞争力大模型体系的潜力[370]。
4.  **需持续突破的技术领域**：下一步需在框架适配、训练效率、推理成本、模型架构及训练方法等方面持续突破[370]。
5.  **安全可信的实施路径**：需将安全可信落实到产品设计和业务流程中，明确数据调用边界、操作确认机制、专业人员复核要求及问题追溯方式[370]。
6.  **典型应用场景实践**：
    *   **基层医疗**：科大讯飞智医助理已覆盖国内800多个区县，提供辅助诊断和风险提示，但不替代医生做最终判断[370]。
    *   **教育场景**：人工智能用于批阅作业和分析错题，帮助教师掌握学情，前提是讲解准确、内容适宜且学生信息得到保护[370]。
7.  **规模化应用的三道门槛**：
    *   **成本门槛**：通过模型优化和端云协同（常规任务本地完成、复杂任务云端按需调用），降低使用成本，让更多企业用得起、用得好[370]。
    *   **场景门槛**：适应复杂工作环境（如现场噪声、方言口音、多人交谈），通过软硬一体打磨及与行业知识、操作规则结合，使AI从问答工具转变为工作助手[370]。
    *   **生态门槛**：需要技术企业、开发者、行业专家和科研机构共同参与，开放能力与工具，共同定义问题、检验效果和改进方案[370]。
8.  **最终价值目标**：人工智能发展的终极价值不仅是让机器完成更多任务，更是让人从繁重、重复劳动中解放出来，充分释放创造力，让更多人分享科技进步成果[370]。

## Event Conclusion

2026年11月2日《人民日报》刊文，从新质生产力视角探讨了人工智能在“十五五”开局之年的发展路径。核心论点是，人工智能的规模化价值创造依赖于自主可控、安全可信的技术底座，需实现芯片、框架、模型、应用的协同，并突破国产算力全链路训练推理能力。文章指出了当前需攻克的技术短板（框架适配、训练效率、推理成本等），并以医疗和教育为例说明了安全可信落地的实践模式。进而，文章提出了跨越成本、场景、生态三道门槛是实现规模化应用的关键，强调了端云协同、软硬一体及多方生态共建的重要性。最终，文章将AI的价值定位为解放人力、释放创造力。由于仅有单一来源，部分具体成效数据和国际对比情况尚待更多信息验证。
