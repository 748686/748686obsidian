# 党的二十届五中全会及全面从严治党决定

## Event Overview

2026年10月26日至29日，中国共产党第二十届中央委员会第五次全体会议（以下简称“党的二十届五中全会”）在北京举行。全会是在中国共产党成立105周年关键节点、中华民族伟大复兴关键时期、“十五五”开局之年召开的一次重要会议。

全会审议通过了《中共中央关于持之以恒推进全面从严治党若干重大问题的决定》（以下简称《决定》），总结了新时代全面从严治党的伟大成就和宝贵经验，分析了当前和今后一个时期管党治党、兴党强党面临的形势和任务，并就持之以恒推进全面从严治党若干重大问题作出系统部署。《决定》单行本已由人民出版社出版，自2026年11月1日起在全国新华书店公开发行。

全会高度评价新时代全面从严治党取得的成就，强调中国共产党在革命性锻造中更加坚强有力。全会指出，确立习近平同志党中央的核心、全党的核心地位，确立习近平新时代中国特色社会主义思想的指导地位，是党在新时代取得的重大政治成果。全会还形成并阐述了“习近平党建思想”，认为其为深入推进新时代党的建设新的伟大工程提供了根本遵循和行动指南。

## Core Facts

### 1. 会议基本信息
*   **时间**：2026年10月26日至29日
*   **地点**：北京
*   **名称**：中国共产党第二十届中央委员会第五次全体会议
*   **背景**：中国共产党成立105周年、中华民族伟大复兴关键时期、“十五五”开局之年

### 2. 《决定》核心内容
全会审议通过的《决定》主要包含以下方面：

*   **指导思想**：坚持马克思列宁主义、毛泽东思想、邓小平理论、“三个代表”重要思想、科学发展观，全面贯彻习近平新时代中国特色社会主义思想，深入学习贯彻习近平党建思想。
*   **总体目标**：确保党始终成为走在时代前列、人民衷心拥护、经得起各种风浪考验、朝气蓬勃的马克思主义执政党，始终成为中国特色社会主义事业的坚强领导核心。
*   **七条原则**：
    1.  坚持服务使命任务
    2.  坚持以党的政治建设为统领
    3.  坚持全面从严
    4.  坚持问题导向
    5.  坚持守正创新
    6.  坚持以上率下
    7.  坚持依规治党
*   **主要任务部署**：
    *   **增强共产党人的党性**：强化对党忠诚教育，用党的创新理论凝心铸魂（突出习近平党建思想），用党的优良传统和中华优秀传统文化涵养党性，在实践中锤炼党性，加强党性鉴别。
    *   **严格贯彻执行民主集中制**：坚持和加强党中央集中统一领导，提高党内民主质量，严格执行领导班子决策议事规则。
    *   **其他部署**：虽然提供的文本在第三部分“严格贯彻执行民主集中制”处截断，但摘要和侧记表明全会对持之以恒推进全面从严治党作出了全面系统部署。

### 3. 习近平党建思想
*   全会指出，在新时代管党治党伟大实践中，习近平总书记围绕建设什么样的长期执政的马克思主义政党、怎样建设长期执政的马克思主义政党的重大时代课题，提出一系列新理念新思想新战略，形成**习近平党建思想**。
*   该思想丰富和发展了马克思主义建党学说，是“两个结合”推进党的理论创新的重大成果，是习近平新时代中国特色社会主义思想的重要组成部分。

### 4. 新时代全面从严治党的成就与形势
*   **成就**：从根本上扭转了管党治党宽松软状况；党的全面领导和党中央集中统一领导显著加强；马克思主义中国化时代化实现新的飞跃；中央八项规定铁律生威；反腐败斗争取得压倒性胜利并全面巩固；党内法规制度体系更为完善。
*   **形势判断（三个“更加艰巨”）**：
    *   从国际看：世界百年未有之大变局加速演进，外部环境不确定难预料因素增多，维护国家主权、安全、发展利益任务更加艰巨。
    *   从国内看：发展进入夯实基础、全面发力的关键时期，进一步全面深化改革等遇到不少新课题，推动改革发展、维护社会和谐稳定任务更加艰巨。
    *   从党内看：党员队伍结构性变化，思想不纯、组织不纯、作风不纯问题尚未根本解决，党保持先进性和纯洁性任务更加艰巨。
*   **“四个考验”与“四种危险”**：执政考验、改革开放考验、市场经济考验、外部环境考验是长期的、复杂的、严峻的；精神懈怠危险、能力不足危险、脱离群众危险、消极腐败危险将长期存在。

### 5. 社会反响与贯彻落实
各地干部群众表示要深入学习贯彻全会精神，以管党治党新成效开创事业发展新局面：
*   **雄安新区**：以高质量党建引领保障高质量疏解发展。
*   **水利系统**：坚持和加强党的全面领导，守护江河安澜。
*   **教育领域**：兰州大学、吉林大学等将全面从严治党要求贯穿于办学治校全过程，引导青年学子读懂全会精神。
*   **基层纪检**：山西省天镇县等聚焦基层民生领域，一体推进不敢腐不能腐不想腐。
*   **航天领域**：海南商业航天发射场将党建融入发射筹备、技术攻关各环节。
*   **新兴领域党建**：天津市河东区打造“红骑先锋”党建品牌，关心关爱新业态劳动者。
*   **国际视角**：国际社会关注全会彰显的自我革新担当，认为其为世界政治文明带来新启迪，打破了唯西方政党模式的迷思。巴基斯坦、乌兹别克斯坦、多哥、尼泊尔等国政党和媒体给予积极评价。
