##  Event Overview

2026年11月2日，《人民日报》第14版（体育版）及第15版（国际版）发布了一系列涵盖体育竞技、体育知识科普、乡村篮球赛事经济效应以及国际政治议题的报道。本次合成涵盖了同一版面内的多个独立报道，包括全国游泳锦标赛（短池）的赛况与规则科普、举重世锦赛中国选手的优异成绩、第四届全国和美乡村篮球大赛（"村BA"）总决赛及其经济带动效应，以及关于日本通过流行文化产品传播错误历史观的国际评论。

## Core Facts

### 1. 体育竞技成绩

**2026年全国游泳锦标赛（25米）**
- **时间/地点**：近日落幕，为期6天。
- **成绩统计**：共产生1项世界纪录、5项亚洲纪录、5项全国纪录及多项全国青年纪录。（来源：ARTICLE #353 / #354）

**2026年举重世锦赛（女子61公斤级）**
- **时间/地点**：2026年11月1日，宁波。
- **金牌得主**：裴鑫依（中国）。
  - 抓举：112公斤
  - 挺举：142公斤（刷新世界纪录）
  - 总成绩：254公斤（刷新世界纪录）
  - 表现：6次试举全部成功，包揽三金。（来源：ARTICLE #355 / #356）
- **银牌得主**：杨柳月（中国，05后选手）。
  - 抓举：110公斤（铜牌）
  - 挺举：139公斤（银牌）
  - 总成绩：249公斤（银牌）
  - 备注：杨柳月刚刚在第二十届亚运会摘金。（来源：ARTICLE #355 / #356）

**第四届全国和美乡村篮球大赛（"村BA"）总决赛**
- **时间/地点**：10月29日晚，湖北省恩施土家族苗族自治州咸丰县高乐山镇小模村。
- **结果**：广东东莞队以95:66战胜东道主湖北咸丰队，夺得冠军。
- **参赛规模**：来自黑龙江宝清县、四川兴文县、广西上林县3个赛区胜出的16支农民球队参赛。（来源：ARTICLE #354 / #355）

### 2. 体育规则科普

**短池与长池游泳的区别**
- **长度差异**：奥运会、世锦赛等长池泳道为50米；短池世锦赛、世界杯等泳道为25米。（来源：ARTICLE #353 / #354）
- **技术差异**：短池中转身次数更多，每隔25米需进行转身、水下腿和重新加速。转身后水下潜行比划水更省力，因此同样距离短池用时更短，纪录分开统计。
- **辅助机制**：400米及以上项目，裁判会在剩余55米时摇铃提醒，铃声持续至运动员游过分道线5米标志处。（来源：ARTICLE #353 / #354）

### 3. "村BA"经济与社会效应

- **基础设施**：咸丰县除学校场地外，拥有标准篮球场276个、三人制篮球场112个、五人制足球场6个，全县人均体育场地面积达3.51平方米。（来源：ARTICLE #354 / #355）
- **当地消费**：总决赛期间举办"村集、村艺、村趣、村游"活动，设50个农产展位、74个美食摊位及50余场主题活动（如南剧展演、摆手舞体验）。县城周边及核心景区接待游客超20万人次。典型案例：摊主王豆豆6天卖出9000余碗土家油茶汤，日销售额破万元。（来源：ARTICLE #354 / #355）
- **赛区带动数据**：
  - 黑龙江宝清县：农特产品和餐饮线上线下销售突破2000万元。（来源：ARTICLE #354 / #355）
  - 四川兴文县：累计接待游客超过12.5万人次，带动综合消费3000万元。（来源：ARTICLE #354 / #355）
  - 广西上林县：接待游客6万人次，综合消费超过1500万元。（来源：ARTICLE #354 / #355）
