# Event Name
Elliott投资德电并反对T-Mobile合并

## Event Overview
美国激进对冲基金Elliott Management通过其子公司Elliott International L.P.在德国电信（Deutsche Telekom）建立了约1.66%的股份（约1200万股），成为德电第六大股东。与此同时，Elliott正联合T-Mobile美国母公司T-Mobile US及其CEO菲利普·亚当斯（Phillip Adams），反对T-Mobile收购美国竞争对手Sprint的390亿美元合并计划。Elliott声称T-Mobile与Sprint的合并将导致消费者每年多支付约15亿美元，并指控T-Mobile及思科（Cisco）在并购前进行了系统性造假，且部分高管在合并期间出售了公司股票。

## Core Facts
1. **持股信息**：Elliott International L.P.持有德国电信12,014,184股普通股，占总股本的1.6619%，位列德电第六大股东。
2. **反对合并**：Elliott联合T-Mobile美国母公司T-Mobile US，公开反对T-Mobile收购Sprint的390亿美元合并计划。
3. **消费者成本指控**：Elliott声称，如果T-Mobile-Sprint合并完成，美国消费者每年将多支付约15亿美元。
4. **造假指控**：Elliott指控T-Mobile及其主要供应商思科（Cisco）在并购前进行了"系统性造假"，且部分高管在合并期间出售了公司股票。
5. **法律威胁**：Elliott发表法律意见称T-Mobile及思科涉嫌欺诈，暗示可能发起集体诉讼；同时警告美国司法部（DOJ）和联邦通信委员会（FCC）若批准该合并将面临反垄断风险。
6. **市场反应**：消息发布后，T-Mobile股价盘前下跌近4%，德国电信股价上涨2%。
7. **Sprint股价波动**：消息公布后，Sprint股价大幅震荡，先涨7.46%至50.19美元，随后又跌5.51%至47.93美元。
