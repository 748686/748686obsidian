# Event Name

US军事高层军官职位削减

## Event Overview

根据提供的资料，美国国防部（DoD）正计划对军事高级领导层进行结构性调整，旨在通过削减近20%的顶级军官职位来节省资金，并增强指挥链的效率与灵活性。这一行动由防长皮特·赫格塞思（Pete Hegseth）推动，被视为其国防战略中精简机构、提升战斗力的一部分。

## Core Facts

1.  **主导人物**：美国防长皮特·赫格塞思（Pete Hegseth）是此次削减计划的主要推动者。
2.  **削减比例**：计划削减约20%的顶级军官职位。
3.  **政策依据**：赫格塞思指示负责人事和战备的国防部副部长道格·柯林斯（Doug Collins）审查所有军种，以确定可裁减的顶级军官职位。
4.  **战略目标**：
    *   **提升效率**：旨在建立一个更“扁平”的指挥结构，减少官僚层级。
    *   **增加灵活性**：消除“死记硬背”的层级，使晋升路径更加公平，并让更有能力的军官脱颖而出。
    *   **应对威胁**：这一改革是赫格塞思更广泛的国防战略的一部分，该战略旨在使美军为与中国等“近敌人”的大规模冲突做好准备，同时解决军种间过度的重叠和复杂性。
5.  **当前状态**：审查正在进行中，尚未最终确定具体裁减哪些职位或军种。
