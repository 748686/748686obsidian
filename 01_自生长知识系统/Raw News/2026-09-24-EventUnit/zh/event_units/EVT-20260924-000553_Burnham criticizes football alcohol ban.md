# Event Name

## Event Overview

利物浦市长安德鲁·伯纳姆（Andrew Burnham）对英格兰足球中针对球迷饮酒的禁令提出批评，将其定性为“歧视”。据报道，自2024-25赛季起，英国足球场内将禁止饮酒。此外，有消息称英超联赛计划引入“禁酒区”作为替代方案。

## Core Facts

- **批评者身份**：安德鲁·伯纳姆（Andrew Burnham），利物浦市长，也是著名利物浦球迷。
- **批评内容**：他将足球场内禁止饮酒的禁令描述为“歧视”。
- **政策背景**：自2024-25赛季起，英国足球场内将全面禁止饮酒。
- **潜在替代方案**：英超联赛可能设置“禁酒区”。
