# 日本经济与政策动态

## Event Overview
2026年11月6日，日本经济领域呈现多重动态。核心经济数据显示，日本名义工资增速创下近30年来最快纪录，反映了劳动力市场的显著变化。与此同时，政策层面正在推动自动驾驶技术的监管改革，以降低技术普及门槛。在经济负担方面，福岛核 disaster 造成的公共负担已超过12万亿日元。此外，作为经济支柱产业之一的丰田公司受强劲需求和日元走弱影响，上调了年度利润预期。

## Core Facts
1. **名义工资创30年新高**：根据日本劳动省（Labor Ministry）周五发布的报告，9月份名义工资同比上涨4.6%，创下自1997年以来的最大年度涨幅。
2. **福岛核污染公共负担**：日本因福岛核 disaster 产生的公共负担总额已超过12万亿日元，相当于每位居民平均承担10万日元。
3. **自动驾驶监管改革**：日本新任监管改革大臣（Regulatory Reform Minister）旨在通过移除限制和收集数据，加速自动驾驶技术的广泛采用。
4. **丰田上调盈利预测**：丰田（Toyota）宣布将年度净利润预测上调至3.57万亿日元，主要归因于强劲的市场需求和日元疲软。
