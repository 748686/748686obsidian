## Event Overview
2026年9月25日，全球科技与安全领域出现多项重要动态。在人工智能（AI）研究领域，LessWrong社区披露了关于预测模型失谐（misalignment）的新基准测试方法以及“伪探针”作为黑盒分析替代方案的研究进展；Ollama发布v0.40.0-rc0版本，为Apple Silicon引入MLX运行时支持；比尔·盖茨通过媒体警告AI潜在的生命威胁风险。与此同时，国际地缘政治与经济方面，中美领导人互动持续引发关注，欧盟边境政策与巴基斯坦局势亦有新进展。在中国，北斗卫星导航系统被定位为新兴支柱产业，且有多篇官方文章探讨中美经济伙伴关系。此外，天文生物学领域证实地球微生物可在模拟土卫二环境下存活。

## Core Facts
1. **AI失谐预测研究**：LessWrong社区报道了一项新方法/基准测试，旨在从训练数据中预测AI模型的失谐（misalignment），可能降低微调后的审计成本。
2. **黑盒可解释性研究**：研究引入“伪探针”（spurious probes）作为激活探针的黑盒替代方案，证明不相关的类别提及问题可可靠地揭示模型内部状态。
3. **Ollama版本更新**：Ollama发布v0.40.0-rc0版本，引入对Apple Silicon的自动MLX运行时支持，取代了兼容模型的默认Metal后端。
4. **VS Code更新**：Microsoft发布Visual Studio Code 1.139.1补丁版本，主要包含错误修复和 minor improvements。
5. **AI安全风险警告**：比尔·盖茨加入其他科技人物，通过《明镜周刊》等渠道警告人工智能存在导致大量死亡风险的生存威胁（existential dangers）。
6. **中国北斗产业发展**：人民日报报道北斗系统正成为新兴支柱产业，打造重要增长极，具有国家战略重要性。
7. **中美外交互动**：法兰克福汇报与明镜周刊报道了习近平与特朗普的外交互动，分析指出冲突不可避免，焦点在于“如何领导冲突”；人民日报文章则强调中美经济纽带及美方商界对中国的信心。
8. **土卫二生命可能性**：卫报报道研究显示地球微生物能在模拟土星卫星土卫二（Enceladus）海洋条件下存活，暗示该卫星可能支持外星生命。
9. **其他地缘事件**：
   - BBC报道威尔士橄榄球队Warrington击败Leeds进入 Grand Final。
   - BBC报道国防部被发现9700万份与SAS调查相关的文件，称为“遗憾”。
   - 沙特阿拉伯拦截胡塞武装导弹，油价升至一周高位。
   - 巴基斯坦因伊姆兰·汗政党誓言进军首都而封锁伊斯兰堡。
