# EVT-20261122-000267 科技博客与AI治理讨论

## Event Overview

本事件综合了2026年11月22日《人民日报》刊载的两篇重要报道。文章一聚焦于中国边远地区医疗卫生资源的下沉与补短板工作，强调“服务上云”及分级诊疗制度的落实；文章二聚焦深圳市推动科技创新与产业创新深度融合的经验与成就，特别是在人工智能、机器人及生物医药领域的进展。两文均呼应了国家关于民生健康与创新发展的宏观政策导向。

## Core Facts

### 1. 边远地区医疗资源下沉与健康短板补齐
*   **政策背景**：2026年10月12日至13日，全国卫生与健康大会上，习近平总书记强调“促进分级诊疗，让群众能就近看得上病、看得好病”及“保障人民健康需要建强卫生与健康系统干部人才队伍”。
*   **西藏医疗支援成效**：
    *   实施医疗人才“组团式”援藏工作（2015年启动），形成“1+7+13”格局（1家自治区医院+7家地市医院+13家县医院）。
    *   西藏7家地市人民医院全部建成三级甲等医院，重点帮扶的13家县医院中已有7家成为二级甲等。
    *   所有“1+7”受援医院均建起胸痛、卒中、创伤、危重孕产妇和危重新生儿五大中心。
    *   大致病情解决情况：400多种“大病”不出自治区、2000多种“中病”不出地市、绝大多数“小病”在县域解决。
*   **新疆医疗人才培育**：
    *   以博尔塔拉蒙古自治州精河县人民医院为例，援疆专家通过“手把手”指导，帮助本地医生（如心血管内科主任齐文明）掌握冠脉造影、起搏器植入等新技术，打造“带不走的医疗队”。
*   **闽宁协作与巡回医疗**：
    *   闽宁协作30周年。福建医疗专家扎根闽宁镇卫生院，培养带头人，配备彩超、CT等设备。
    *   国家卫生健康委自2011年起组建国家巡回医疗队，2025年要求建立常态化巡回医疗制度。2026年已组建89支国家医疗队，深入中西部薄弱地区开展义诊。
*   **典型案例**：青海省玉树藏族自治州杂多县（海拔4000多米）县人民医院建起青海海拔最高的血液透析室，使患者色英能在家门口接受治疗。

### 2. 深圳科技创新与产业融合
*   **高层评价**：2026年11月18日，习近平主席在亚太经合组织（APEC）工商领导人峰会及领导人非正式会议欢迎晚宴上，肯定深圳从边陲小镇到国际化大都市的跨越，指出“创新是深圳的活力所在”，并强调强化企业主体地位，推进“四链”（创新链、产业链、资金链、人才链）深度融合。
*   **创新数据**：
    *   2025年战略性新兴产业增加值1.67万亿元，占GDP比重43%。
    *   全社会研发投入2750.76亿元，研发投入强度7.10%。
    *   90%以上的创新型企业、研发机构、研发人员、研发资金及职务发明专利出自企业；2025年企业研发投入占比超93%。
    *   80%以上科研选题由企业提出，95%以上攻关项目由企业牵头。
    *   深圳PCT国际专利申请量连续22年居全国城市第一。
    *   “深圳—香港—广州”创新集群蝉联《2026年全球创新指数报告》全球首位。
*   **典型企业与项目**：
    *   **优艾智合机器人**：研发移动机器人搬运晶圆，定位偏差<2mm，损耗近乎为零，获2025年度广东省科学技术奖技术发明奖一等奖。
    *   **华大集团**：牵头国家重点研发计划专项，实现生物试剂国产化量产突破。
    *   **大疆与西安交大**：联合攻克芯片架构设计及核心算法难点。
    *   **比亚迪**：联合上下游破解碳化硅功率器件银烧结焊接工艺难题。
    *   **深圳先进院**：马腾团队研发的超高清双频率血管内超声成像诊断设备及配套导管获批上市，实现全球应用于人体的血管内超声最高工作频率。
*   **平台与设施**：
    *   建成鹏城实验室，牵头/参与建设全国重点实验室20家，建有4家省实验室，各级各类创新载体超4000家。
    *   深圳先进院与企业合作成立超300个创新联合体，横向合作金额超23亿元。
    *   光明科学城：“灵晟”系统登顶全球超算TOP500，“鹏城云脑Ⅲ”拿下IO500双料第一；合成生物、脑解析等大科学装置开放共享机时逾19万小时。
*   **应用场景与产业**：
    *   累计发布5批近300个“城市+人工智能”应用场景。
    *   越疆科技人形机器人在商场担任“爆米花店员”；龙岗“龙小二”人工智能原生城市治理智能体日均感知近20万条数据。
    *   腾讯与迈瑞医疗联合研发“启元重症大模型”，已在全国多地医院使用。
    *   2025年人工智能核心产业营收超2200亿元，规上企业超2600家。
    *   2025年全球人形机器人出货量前五中，深圳企业占三席。
    *   设立100亿元人工智能和具身机器人产业基金、50亿元人工智能终端产业投资基金。

*   **健康领域**：边远地区群众就医便利性显著提升，大病、中病、小病分级诊疗格局初步形成，医疗人才队伍本地化能力增强。

## Event Conclusion

2026年11月22日《人民日报》头版刊登的两篇文章，分别从**医疗卫生资源均衡配置**和**科技创新驱动产业发展**两个维度，展示了中国在国家治理现代化进程中的实践成果。一方面，通过“组团式”援藏援疆、巡回医疗、闽宁协作等措施，有效补齐了边远地区健康短板，推动了分级诊疗落地；另一方面，深圳通过强化企业创新主体地位、促进“四链”融合、开放应用场景，打造了具有全球影响力的产业科技创新中心，并在人工智能、机器人等领域取得领先地位。两篇文章共同体现了“以人民为中心”的发展思想和“创新是引领发展的第一动力”的战略导向。
