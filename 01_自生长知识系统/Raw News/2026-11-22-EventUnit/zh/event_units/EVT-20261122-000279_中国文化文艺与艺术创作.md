# EVT-20261122-000279 中国文化文艺与艺术创作

## Event Overview

2026年11月22日，《人民日报》发表多篇涉及文化艺术、美术教育及乡村文化振兴的主题内容。本事件核心聚焦于高等美术院校如何通过“艺术乡建”转变育人模式，将乡土现场转化为制度化的育人课堂。文章由中国美术学院党委书记沈浩撰写，系统阐述了中国美术学院“以乡土为学院”的教育理念及其在福建宁德等地的实践成果，强调了从“送文化下乡”向“以乡土为学院”的范式转移，以及从“项目逻辑”向“制度逻辑”的可持续性转变。

## Core Facts

- **时间**：2026年11月22日
- **来源**：人民日报（People's Daily）
- **版面**：第08版副刊（艺坛走笔）
- **文章标题**：《把乡土作为育人现场》
- **作者**：沈浩（中国美术学院党委书记）
- **核心观点**：
    1. 艺术乡建是高等美术院校服务社会的重要路径，但需解决“做项目”与“育新人”的关系问题。
    2. 乡村全面振兴需要人才支撑，艺术乡建应从“项目逻辑”转向“制度逻辑”。
    3. 中国美术学院提出“以乡土为学院”教育理念，将乡土视为艺术教育的“内在现场”。
    4. 实践数据：历经10余年深耕，已搭建覆盖28个省份的乡土学院网络，累计组织8万余名师生深入一线，参与美丽乡村建设服务项目500余个。
    5. 案例：福建宁德乡土学院。2017年始于前汾溪村一间荒废老屋，现建成5300平方米实体基地。建立“本科生驻村半年以上、研究生驻村两年以上”的制度，形成“前一届学生—返乡校友—在地组织者”三级传帮带体系。
    6. 方法：以“微更新、轻介入”方式修复乡村肌理、激活古建价值、重塑乡村气质；坚持“不替村民做主”的专业伦理。
    7. 目标转变：从“给乡村送文化”转变为“在乡村‘种’文化”，赋予村民重新看见自家价值、讲述地方故事、进行文化创造的能力。
    8. 政策呼应：符合《“文艺赋美乡村”工作方案（2025—2027年）》关于“壮大乡村文化人才队伍，激活乡村文化内生动力”的要求。
    9. 评价尺度：学生离开后村民是否还有创造能力；项目结项后地方是否还有自我更新可能；乡土现场是否仍在“生长”应对新问题的方法。

## Event Conclusion

2026年11月22日，《人民日报》刊发中国美术学院党委书记沈浩撰写的《把乡土作为育人现场》一文，系统阐述了中国美术学院在艺术乡建领域的教育理念与实践成果。文章指出，艺术乡建应从“做项目”转向“育新人”，从“送文化”转向“种文化”。通过建设覆盖28个省份的乡土学院网络，并将驻村实践制度化（本科半年、研究生两年），中国美术学院探索出一条高校与乡村双向塑造、互相成就的育人路径。这一实践不仅回应了乡村全面振兴对人才的需求，也为高等美术教育如何扎根大地、服务社会提供了重要范式。
