# Event Name

## Event Overview
2026年9月11日，中央纪委国家监委通报了对新疆生产建设兵团原党委常委、副司令员李旭严重违纪违法问题的审查调查结果。经中共中央批准，李旭被开除党籍，并由国家监委给予其开除公职处分。调查发现李旭存在违反政治、组织、廉洁和生活纪律的行为，以及利用职务便利为他人谋利并收受巨额财物的受贿犯罪嫌疑。相关案件及涉案财物已移送检察机关依法审查起诉。该消息于2026年9月12日通过《人民日报》公开发布。

## Core Facts
*   **涉案人员**：李旭，职务为新疆生产建设兵团原党委常委、副司令员。
*   **处理结果**：
    *   依据《中国共产党纪律处分条例》等规定，经中央纪委常委会会议研究并报中共中央批准，给予李旭**开除党籍**处分。
    *   依据《中华人民共和国公职人员政务处分法》等规定，由国家监委给予李旭**开除公职**处分。
    *   终止其新疆维吾尔自治区第十次党代会代表、新疆生产建设兵团第八次党代会代表、新疆生产建设兵团第九师第八次党代会代表资格。
    *   收缴其违纪违法所得。
    *   将涉嫌犯罪问题及所涉财物移送检察机关依法审查起诉。
*   **违规违法事实**：
    *   **政治纪律方面**：丧失理想信念，背弃初心使命，搞政治投机，结交政治骗子，长期搞迷信活动。
    *   **中央八项规定精神方面**：接受可能影响公正执行公务的宴请，无偿接受私营企业主提供的车辆和司机服务，将应由本人支付的费用由他人支付。
    *   **组织纪律方面**：违反组织原则，不按规定报告个人有关事项，在职务提拔、职工录用等工作中为他人谋取利益，在组织函询时不如实说明问题。
    *   **廉洁纪律方面**：违规收受礼品、礼金。
    *   **法律责任方面**：利用职务便利为设备采购、工程项目承揽、土地性质变更等提供便利，非法收受巨额财物，涉嫌受贿犯罪。
*   **时间节点**：
    *   电头时间：2026年9月11日。
    *   发布平台：2026年9月12日《人民日报》第04版。
