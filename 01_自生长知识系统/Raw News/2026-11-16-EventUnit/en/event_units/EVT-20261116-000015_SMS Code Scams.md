# EVT-20261116-000015: SMS Code Scams

## Event Overview

This event addresses a social engineering tactic where scammers deceive users into revealing one-time SMS verification codes. The specific pretext reported involves fraudsters posing as support personnel claiming to help remove phone numbers from chat applications, thereby tricking victims into surrendering the authentication codes required to access or control those accounts.

## Core Facts

*   **Modus Operandi:** Scammers contact victims under the guise of customer support or technical assistance.
*   **Specific Pretext:** Fraudsters claim they are removing a phone number from a chat service/application.
*   **Objective:** To induce the victim to read aloud or forward an SMS code sent to their device.
*   **Outcome Risk:** Possession of the SMS code typically allows the attacker to bypass two-factor authentication (2FA) or perform account takeover procedures on messaging platforms.
