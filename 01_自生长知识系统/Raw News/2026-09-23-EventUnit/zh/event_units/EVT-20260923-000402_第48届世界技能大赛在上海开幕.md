# 第48届世界技能大赛在上海开幕

## Event Overview
2026年9月22日，第48届世界技能大赛在上海隆重开幕。这是该赛事首次在发展中国家举行。大赛主题为“技能改变世界 技能照亮前程”，由世界技能组织主办，中华人民共和国人力资源和社会保障部与上海市人民政府共同承办。比赛期间（9月22日至27日）还将举办世界技能大会和世界技能博览会。

本次大赛受到中方高度重视，国家主席习近平向大赛致贺信，国务院总理李强会见世界技能组织高层领导，马来西亚、吉尔吉斯斯坦等国总理级领导人应约出席相关活动。

## Core Facts
*   **时间**：2026年9月22日开幕，为期至9月27日。
*   **地点**：中国上海。
*   **主办方**：世界技能组织（WorldSkills International）。
*   **承办方**：中国人力资源社会保障部、上海市人民政府。
*   **主题**：“技能改变世界 技能照亮前程”。
*   **重要活动**：大赛期间将举办世界技能大会和世界技能博览会。

## Cross-Source Verification
*   **习近平致贺信**：Article #517（人民日报要闻版）明确报道，9月22日习近平向第48届世界技能大赛致贺信，指出大赛紧密对接产业需求，中国愿同各方加强交流合作。
*   **开幕时间与地点**：Article #517及Article #524（外交部发言人消息）均确认大赛于9月22日在上海开幕。
*   **外国领导人出席**：Article #524证实，应中方邀请，马来西亚总理安瓦尔将出席世界技能大赛开幕式，吉尔吉斯斯坦总理卡瑟马利耶夫将出席全球数字贸易博览会启动仪式（二者同期举行）。
*   **高层会见**：Article #526报道，9月22日下午，国务院总理李强在上海会见世界技能组织主席乌汉（Uhan）和首席执行官霍伊（Hoy）。

*   **具体倡议**：愿同各方加强交流合作，推动世界技能运动发展，更好服务全球经济增长和民生福祉改善。
