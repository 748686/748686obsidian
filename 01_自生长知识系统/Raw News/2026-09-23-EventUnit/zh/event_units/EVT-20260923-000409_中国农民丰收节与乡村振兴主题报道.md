# EVT-20260923-000409 中国农民丰收节与乡村振兴主题报道

## Event Overview

2026年9月23日（农历秋分），中国迎来第九个“中国农民丰收节”。当日，《人民日报》推出系列报道，涵盖总书记节日贺词、农业科技创新理论文章、田间丰收视觉画卷、乡村振兴典型案例以及重庆主会场活动报道。该系列报道围绕三农政策宣传、乡村振兴实践展示及农业强国建设理论解读展开。

## Core Facts

- **时间节点**：2026年9月23日为农历秋分，是第九个“中国农民丰收节”。
- **最高层问候**：习近平总书记代表党中央向全国广大农民和工作在“三农”战线上的同志们致以节日祝贺和诚挚问候。
- **总书记指示要点**：扎实推进乡村全面振兴，提高强农惠农富农政策效能，着力提升农业综合生产能力和质量效益，拓宽农民增收致富渠道，因地制宜建设宜居宜业和美乡村，努力让广大农民生活更加幸福美好。
- **秋粮生产形势**：南方双季晚稻进入孕穗抽穗产量形成关键期，北方秋粮处于灌浆成熟期，预计不到半个月大面积收获。全国秋粮播种面积稳中有增、大部分长势正常。
- **科技壮举**：今年我国首次启动20个大面积单产提升整建制推进市；农业科技进步贡献率超过64%。
- **重庆主会场**：2026年中国农民丰收节重庆市主会场暨第三届农民农耕赛事运动会在重庆市荣昌区清江镇河中岛举行。
- **理论支撑**：《人民日报》理论版刊发中国农业科学院文章，系统论述以农业科技创新支撑农业强国建设的战略路径。
