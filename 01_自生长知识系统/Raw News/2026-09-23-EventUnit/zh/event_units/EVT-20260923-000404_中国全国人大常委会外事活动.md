# 中国全国人大常委会外事活动

## Event Overview
2026年9月21日至23日期间，中国全国人大常委会两位副委员长分别开展了双边和多边外交活动。丁仲礼副委员长率团访问韩国，出席第十四次中韩议会交流机制会议；雪克来提·扎克尔副委员长在北京出席全球可持续交通高峰论坛（2026）开幕式及跨里海国际运输走廊高级别会议，并开展相关双边会见。

## Core Facts
1. **丁仲礼访韩**：
   - 时间：2026年9月21日至22日。
   - 地点：韩国。
   - 主要活动：应韩国国会邀请，会见韩国国会议长赵正湜，与南仁顺副议长共同出席中韩议会交流机制第十四次会议。
   - 中方立场：强调坚守建交初心、坚定睦邻友好、坚持互利共赢，落实两国元首共识，推动各领域合作。
   - 韩方立场：愿与中方一道推动两国战略合作伙伴关系向更加成熟阶段发展。
   - 议题：双边关系、地区形势、经济科技合作、妇女儿童权益；韩方重申尊重一个中国立场。

2. **雪克来提·扎克尔出席国际会议**：
   - 时间：2026年9月22日。
   - 地点：北京。
   - 主要活动：出席全球可持续交通高峰论坛（2026）开幕式、跨里海国际运输走廊高级别会议并致辞。
   - 中方立场：愿同各方落实元首外交重要共识，推进全球交通可持续发展，推动跨里海国际运输走廊提质扩能增效，争取互利共赢成果。
   - 双边会见：开幕式前会见阿塞拜疆副总理穆斯塔法耶夫和吉尔吉斯斯坦副总理阿昆别科夫。

3. **其他动态**：
   - 马来西亚总理安瓦尔等外国领导人将出席第48届世界技能大赛和第五届全球数字贸易博览会（报道提及，无详细过程）。
