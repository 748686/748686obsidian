# Event Name
2026年杭州亚运会中国代表团夺金与女排三连冠

## Event Overview
2026年9月22日至23日，第二十届杭州亚运会中国代表团在多个项目上取得突破。9月22日为开幕式后第三个比赛日，中国队表现优异，共斩获9枚金牌。当日比赛结束后，中国代表团金牌总数累计达到32枚。其中，中国女排在决赛中战胜日本队，实现亚运会三连冠；射击选手王子菲/盛李豪在10米气步枪混合团体项目中打破世界纪录；游泳、自行车、武术等项目均有金牌入账。

## Core Facts

**1. 中国代表团金牌汇总**
*   **时间点**：截至2026年9月22日比赛结束。
*   **新增金牌**：9枚。
*   **累计成绩**：金牌32枚、银牌13枚、铜牌8枚。
*   **来源**：Article #542（人民日报，第10版）。

**2. 中国女排获得亚运会三连冠**
*   **时间**：2026年9月22日晚。
*   **赛事**：第二十届亚运会女排决赛。
*   **对手**：日本女排。
*   **比分**：中国队以3:0战胜日本队（第一局25:19，第二局25:20，第三局25:23）。
*   **意义**：这是中国女排队史第十枚亚运金牌，实现亚运会三连冠。
*   **关键球员**：吴梦洁（全场最高29分）、王奥芊（17分）、庄宇珊、王梦洁等。
*   **背景**：此前8月30日女排亚锦赛决赛中，中国队曾以2:3负于泰国队获得亚军，此次夺冠被视为重整旗鼓、重塑信心。
*   **来源**：Article #541、Article #542。

**3. 射击项目打破世界纪录**
*   **时间**：2026年9月22日上午。
*   **项目**：10米气步枪混合团体决赛。
*   **选手**：王子菲、盛李豪。
*   **成绩**：以507.1环的成绩夺得冠军，同时打破该项目资格赛和决赛两项世界纪录。
*   **其他名次**：韩国队亚军，日本队季军。
*   **背景**：两人本赛季已实现国际射联全项世界杯三连冠，首次携手参加亚运会。
*   **来源**：Article #543、Article #542。

**4. 其他金牌项目**
*   **公路自行车**：郭莉在女子个人赛中，以微弱优势（半个车轮）战胜阿富汗选手哈希米，成绩同为2小时50分05秒。这是中国队自1994年广岛亚运会后时隔32年再夺该项目冠军。
*   **游泳**：
    *   彭旭玮：女子200米仰泳冠军，成绩2分05秒77，打破亚洲纪录（尘封16年）。
    *   张展硕：男子1500米自由泳冠军。
    *   李冰洁：女子400米自由泳冠军。
    *   徐嘉余、董志豪、徐放、潘展乐：男子4×100米混合泳接力冠军，实现该项目亚运会四连冠。
    *   *注*：游泳项目共获4金2银2铜。
*   **武术**：
    *   李剑鸣：男子南拳南棍全能冠军（19.563分）。
    *   张雅玲：女子南拳南刀全能冠军。
*   **来源**：Article #542。
