# 李强上海调研与蔡奇出席长征胜利90周年纪念活动

## Event Overview

2026年9月22日，中国发生两项重要国内政治活动：一是中共中央政治局常委、国务院总理李强在上海调研先进制造业及未来产业发展情况；二是“伟大的远征——纪念中国工农红军长征胜利90周年主题展览”开幕式在北京中国人民革命军事博物馆举行，中共中央政治局常委、中央书记处书记蔡奇出席并讲话。这两项活动同日被《人民日报》头版报道，反映了中国在推动经济高质量发展与传承革命精神两个维度的并重。

## Core Facts

### 1. 李强上海调研先进制造业

- **时间**：2026年9月22日
- **地点**：上海
- **主要人物**：中共中央政治局常委、国务院总理李强；陈吉宁、吴政隆参加调研
- **调研内容**：
  - 听取关于“人工智能+”集成服务商、人工智能原生工厂建设情况汇报
  - 察看专用机器人、工业机器人产品及在复杂场景中的应用展示
  - 参观智能机器人装配调试中试车间
  - 了解上海未来启点社区（专注未来产业领域的科创孵化平台）创新生态建设及上海未来产业基金运行情况
  - 察看脑机接口、量子计算等领域技术产品
- **核心指示**：
  - 深入贯彻落实习近平总书记关于发展先进制造业的重要指示和全国先进制造业大会精神
  - 坚持智能化、绿色化、融合化方向
  - 推进科技创新和产业创新深度融合
  - 大力发展新一代智能制造
  - 加快培育壮大新兴产业和未来产业
  - 持续做大做强先进制造业
  - 纵深推进“人工智能+制造”，促进全流程智能升级
  - 激活数据要素潜能，带动行业全面数智化转型
  - 打造智慧产业链供应链
  - 瞄准制造领域共性难题，打造制造业生产服务平台
  - 助力企业特别是中小企业开展智能化改造
  - 加强对未来技术发展的跟踪分析和研判
  - 强化关键核心技术攻关，筑牢基础研究支撑
  - 鼓励大胆探索、包容试错
  - 构建一流创新生态，推动产学研用深度融合
  - 大力发展创业投资，壮大耐心资本
  - 建立未来产业投入增长和风险分担机制
  - 人才是第一资源，强化人才集聚培养功能

### 2. 长征胜利90周年纪念展览开幕式

- **时间**：2026年9月22日上午10时
- **地点**：北京中国人民革命军事博物馆
- **展览名称**：“伟大的远征——纪念中国工农红军长征胜利90周年主题展览”
- **主要人物**：
  - 出席并宣布展览开幕：蔡奇（中共中央政治局常委、中央书记处书记）
  - 出席：尹力、李书磊、张升民、洛桑江村、王勇
- **参与人员**：中央党政军有关部门和北京市负责同志，驻京部队官兵和首都各界群众代表等约600人
- **仪式流程**：
  - 中国人民解放军军乐团奏响《义勇军进行曲》
  - 全场高唱中华人民共和国国歌
  - 全场肃立，向在长征中英勇牺牲的革命先烈默哀
- **展览规模**：
  - 共分7个部分
  - 展出照片图表357张
  - 展出文物文献1061件（套）
- **核心讲话内容**：
  - 长征胜利实现了中国共产党和中国革命事业从挫折走向胜利的伟大转折
  - 开启了中国共产党为实现民族独立、人民解放而斗争的新的伟大进军
  - 是中华民族伟大复兴历史进程中的巍峨丰碑
  - 伟大长征精神已深深融入中华民族的血脉和灵魂
  - 主题展览全景式展现党领导红军进行长征的光辉历程、宝贵经验、伟大意义、深远影响
  - 展示党的十八大以来党领导人民继承和发扬革命传统、不断创造新的历史辉煌的壮阔征程
  - 为开展理想信念教育、爱国主义教育和革命传统教育提供重要平台
  - 引导干部群众深刻认识红色政权来之不易、新中国来之不易、中国特色社会主义来之不易
  - 强调要更加紧密地团结在以习近平同志为核心的党中央周围
  - 全面贯彻习近平新时代中国特色社会主义思想
  - 深刻领悟“两个确立”的决定性意义
  - 坚决做到“两个维护”
  - 大力弘扬伟大长征精神
  - 走好新时代的长征路
  - 为以中国式现代化全面推进强国建设、民族复兴伟业而不懈奋斗
