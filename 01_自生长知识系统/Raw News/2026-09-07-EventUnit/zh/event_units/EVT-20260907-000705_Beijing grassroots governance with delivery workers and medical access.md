# Event Name
北京快递小哥参与基层治理与四川山区就医便利化

## Event Overview
2026年9月7日，《人民日报》头版刊发了两则报道。一则关注北京市通过思想政治工作引领，推动快递、外卖等新就业群体融入基层社会治理，发挥“流动哨兵”作用；另一则报道四川省巴中市推进紧密型县域医共体建设，通过资源下沉和数字化手段，改善山区群众就医条件。这两项举措均旨在落实以人民为中心的发展思想，提升基层治理效能和公共服务水平。

## Core Facts

### 一、 北京：新就业群体融入基层治理
1. **政策背景**：北京深入贯彻落实总书记关于关注新业态发展、做好新就业群体思想引导和凝聚服务工作的指示精神。
2. **规模数据**：北京拥有快递从业人员近10万人，其中一线快递员6.5万人。
3. **主要模式与成效**：
   - **察民情**：快递员担任“流动哨兵”。例如，顺丰快递员刘阔与独居老人建立“窗帘之约”，西城区通过该机制一年排除3起老人遇险情况；西城区将10类新就业群体编入“城市响应人”队伍，2025年新增快递小哥社区报到2000余人，上报问题线索1.7万条。
   - **聚合力**：朝阳区推行“双站长制”（企业站长+社区党委书记），在“东风快递小院”等阵地提供暖新驿站、食堂等服务。累计选派690余名“双站长”，响应诉求800余项；站点小哥为孤寡老人义务送餐8600多趟。
   - **助发展**：美团骑手高丰作为北京市人大代表，通过党支部收集建议（如补全国小区楼牌号、加装无障碍坡道等），并在两会期间提出，推动举措落地。2025年，北京推动2300余名快递员参与友好场景建设，4000余名担任“文明宣传员”，服务居民超6000人次。

### 二、 四川巴中：紧密型县域医共体提质升级
1. **政策背景**：巴中地处川陕革命老区，曾面临县级以下医院实力弱、山区群众看病难问题。当地落实总书记关于引导医疗卫生工作重心下移、资源下沉的指示精神。
2. **核心机制**：
   - **组织形式**：以平昌县人民医院领办的平州总医院为核心，包含20个原乡镇卫生院，打造紧密型县域医共体。
   - **服务模式**：搭建信息共享平台，实现“基层检查、县级诊断、结果互认”。例如，心电图数据实时传输至县医院心电诊断中心。
   - **人才下沉**：县医院中级及以上职称人员常驻乡镇分院，既坐诊又培训。2025年下半年计划再有10名医生下沉。
   - **慢病管理**：利用智慧慢病管理系统，对近2000名慢性病患者进行远程血压、血糖监测。
3. **成效数据**：2025年，巴中市基层诊疗量占比达68.18%，居四川各市州前列。通江县、南江县、恩阳区等地也通过不同方式整合资源，打造特色县域医共体。

## Event Conclusion
2026年9月7日《人民日报》报道了北京和四川两地在社会治理与民生保障方面的最新进展。北京通过“双站长制”、“城市响应人”等机制，成功将快递外卖小哥纳入基层治理体系，实现了从“流动”到“留心”的转变，提升了城市治理精细化水平。四川巴中通过建设紧密型县域医共体，推动优质医疗资源下沉，利用数字化手段实现“基层检查、县级诊断”，显著改善了山区群众就医条件，基层诊疗量占比领先全省。两则报道共同体现了中国政府在不同领域深化供给侧改革、提升公共服务效能和治理能力的努力。
