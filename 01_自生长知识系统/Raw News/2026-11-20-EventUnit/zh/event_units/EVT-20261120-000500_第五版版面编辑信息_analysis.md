# Event Analysis

## 标题：毕节试点经验推动全省外出务工人员保障机制建设

## 作者：网络公开报道（《人民日报》记者马跃峰、苏滨）

## 标签
社会治理、劳务输出、民生保障、精准扶贫、政策试点、贵州省毕节市

## 一句话总结这篇文文章
《人民日报》2026年11月20日报道贵州毕节通过完善“一老一小”照料、基层自治及劳务维权等机制，解决193万外出务工人员后顾之忧，其试点经验已上升为省级15条指导意见。

## 总结文章内容并写成摘要

**背景与核心议题**
报道聚焦贵州省毕节市这一劳务人口大市（193万人外出务工，其中157万人跨省），针对务工群体普遍面临的留守老人儿童照料难、家庭事务缺失、维权困难等“急难愁盼”问题，探索并实施了一套系统性的保障机制。该机制旨在让外出务工人员无后顾之忧地参与经济活动，因为务工收入在脱贫家庭和易地搬迁家庭中分别占比70%和90%。

**主要做法与成效**
毕节市的实践主要体现在三个维度：
1.  **完善公共服务体系**：重点解决“一老一小”问题。建成运营养老机构及日间照料中心、互助幸福院；依托儿童之家提供心理咨询和假期托管。案例显示，七星关区大新桥街道和织金县惠民街道已通过老年食堂和公益托管班惠及大量群众。
2.  **强化基层社会治理**：组建群众自治组织（如金沙县禹谟镇中坪村的“孃孃帮”服务队），制定互助服务清单，构建市、县、乡、村四级联动解忧责任体系，累计争取资金近60亿元。
3.  **提升维权与就业服务能力**：在省外建立25个劳务协作站，配备法律顾问和专职维权人员。2024年以来累计追回欠薪5.63亿元惠及3.44万名农民工；实施“技能照亮前程”行动，完成技能培训7.86万人次。

**政策推广与影响**
基于毕节的成功试点，贵州省于2026年7月印发《关于建立完善支持保障机制解决外出务工人员后顾之忧的指导意见》，从强化关心关爱、加强综合治理、提升公共服务水平等5个方面提出15条指导意见，将地方经验上升为省级制度安排。该报道是学习贯彻党的二十届五中全会精神系列报道之一，体现了国家层面对乡村振兴和民生保障的重视。

**二、 核心报道：毕节外出务工人员保障体系**
   1. **问题背景**
      - 贵州省劳务输出大省地位（常年600万人左右）
      - 毕节市数据：193万人外出，157万人跨省
      - 收入依赖度：脱贫家庭70%，搬迁家庭90%
   2. **政策脉络**
      - 2024年以来毕节聚焦破解急难愁盼问题
      - 2026年7月贵州省出台15条指导意见，推广毕节经验
   3. **具体措施与成效**
      - **关爱“一老一小”**
         - 设施建设：养老机构112家，日间照料中心62个，互助幸福院89个
         - 儿童服务：心理咨询、假期托管，惠及68万人次
         - 典型案例：大新桥街道老年食堂、织金县公益托管班
      - **基层社会治理创新**
         - 组织形式：群众自治组织2800余个
         - 服务内容：就医陪护、家事劳作、农事帮衬等12类清单
         - 典型案例：“孃孃帮”服务队（王宏珍队长，留守妇女组成）
         - 资金保障：累计争取近60亿元，四级联动解忧体系
      - **维权与就业服务**
         - 平台搭建：25个省外劳务协作站，配备公益法律顾问
         - 维权成果：追回欠薪5.63亿元，帮助3.44万名农民工
         - 就业扶持：技能培训7.86万人次，发布岗位47.9万个
         - 典型案例：黔西市驻温州协作站3天帮助工伤职工李军获赔
   4. **个体故事视角**
      - 吴学兴：因照顾生病父亲失业，通过家乡服务重获稳定工作
      - 李军：工伤维权从繁琐到高效的转变
