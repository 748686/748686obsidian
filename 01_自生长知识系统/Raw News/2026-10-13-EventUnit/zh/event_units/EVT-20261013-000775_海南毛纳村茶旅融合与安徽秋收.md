## Core Facts

### 1. 南京六合区空天产业发展
**来源**：Article #495 (人民日报, 2026-10-13, 第07版)

| 类别 | 事实 |
|------|------|
| **项目** | 星河动力航天公司中大型可重复使用液体运载火箭——智神星一号于9月1日在酒泉卫星发射中心升空，将载荷准确送入预定轨道。 |
| **基地** | 星河动力大推力液体火箭总装基地位于江苏省南京市六合区，距离南京市中心约40公里。智神星二号火箭生产正在紧锣密鼓筹备中。 |
| **投资与产能** | 基地一期总投资约20亿元，承担大型可复用液体火箭总装总测任务，设计年产能达10发火箭。 |
| **产业格局** | 形成“一体两翼一港”产业格局，由南航国际创新港、空天数智产业园、航空航天产业园、六合空天港串联而成的“空天创造走廊”加速崛起。 |
| **创新平台** | 已引入6个全国重点实验室、10个校企联合实验室、13个省部级创新平台。 |
| **技术成果** | 复杂产品智能制造系统技术全国重点实验室通过线激光扫描、计算机视觉引导，将铣削精度提高5至10倍。 |
| **企业孵化** | 南京航空航天大学研究员王长瑞2021年创办公司，将金刚石与金属有效结合的散热技术成果孵化为项目，服务多家芯片制造商，产品已迭代到第三代。 |
| **签约活动** | 2026年6月，第四届航空航天产创融合推介活动在六合区举办，仰望航天精密结构件研发生产、星河动力研发中心等15个项目集中签约。 |
| **数控机床** | 六合高端数控机床产业园集聚130多家机床产业链企业，园区能配齐90%以上的机床零部件。南京速锋数控技术有限公司与南京航空航天大学共研的定位器已用于国产大飞机C919。 |
| **招商** | 2025年成功招引通用技术集团落户，共同开展精密数控机床核心技术攻关。 |
| **经济表现** | 2025年六合区规上工业总产值实现双位数增长；2026年上半年也实现大幅增长。 |
| **官员表态** | 区长荣飞：“因地制宜，不是追逐风口，而是找到自身禀赋与产业需求的‘交集’。”区委书记周勇表示将打造江苏省商业航天产业发展重要阵地，协同发展新能源、高端新型材料、高端智造装备、航空航天四大先进制造业产业集群。 |
