# Event Name

## Event Overview

2026年9月13日，《人民日报》第08版刊发刘欲晓撰写的文章《一场“艺术长征”》，报道了正在国家大剧院艺术馆举办的“红飘带之行——沈尧伊长征路写生作品展”。该展览甄选了近200幅水粉、丙烯、油画等类别作品，其中特别包含了沈尧伊在1975年和1977年两次重走长征路期间完成、尘封约半个世纪的首度公开写生原稿。文章指出，沈尧伊历时50余年深耕长征题材，坚持“无踏勘不落笔”的创作准则，通过实地考据构建起体系完备的长征主题图像谱系，包括油画《遵义会议》及大型连环画《地球的红飘带》等。

## Core Facts

*   **展览名称**：“红飘带之行——沈尧伊长征路写生作品展”。
*   **展览地点**：国家大剧院艺术馆。
*   **报道时间**：2026年9月13日。
*   **主要人物**：沈尧伊（画家）、刘欲晓（报道作者）、李桦（沈尧伊的导师）。
*   **展品规模与类型**：甄选近200幅作品，包含水粉、丙烯、油画等类别。
*   **核心亮点**：首次对外公开沈尧伊于1975年、1977年两次重走长征路期间完成的写生原稿。
*   **历史足迹**：
    *   1975年：从赣南启程，历时3个月沿红军行军轨迹北上。
    *   1977年：再次重走长征路，查漏补缺。
*   **代表性作品**：
    *   写生作品：《延安宝塔山》（文中提及的水粉画）、描绘泸定铁索、雪山草地、雄关古道、瑞金、娄山关、金沙江的小幅水粉写生。
    *   经典油画：《革命理想高于天》、《而今迈步从头越》、《遵义会议》、《瓦窑堡会议》、《飞夺泸定桥》、《血战湘江》。
    *   新近作品：《疾进腊子山》、《张家界的红军路》、《翻越雪山》等6幅油画。
    *   大型连环画：《地球的红飘带》。
*   **创作理念**：遵循“无踏勘不落笔、无史实不创作”的准则，强调艺术真实根植于现场体悟。
