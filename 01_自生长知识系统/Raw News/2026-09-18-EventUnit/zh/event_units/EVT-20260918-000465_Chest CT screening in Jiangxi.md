# Event Name

北京胸科医院在江西于都开展免费胸部CT联合筛查“长征行”项目

## Event Overview

2026年8月29日，首都医科大学附属北京胸科医院牵头、中国控烟与健康协会协办的“控烟护肺·一扫双筛”肺癌、肺结核联合筛查“长征行”项目在江西于都县启动。该项目依托移动诊疗车，在革命老区于都县长征源社区和思源社区开展免费胸部低剂量螺旋CT筛查。同日，项目组累计完成568人次筛查，并开展专家现场阅片与本地医生带教培训。该活动是“三年百万筛查行动”的重要组成部分，旨在将三甲医院标准的肺部检查服务送达基层，并实现“既送筛查，又留技术”。

*注：该事件信息主要来源于2026年9月18日《人民日报》报道，报道提及的事件发生时间为8月29日。*

## Core Facts

1.  **活动主体**：
    *   牵头单位：首都医科大学附属北京胸科医院（简称北京胸科医院）。
    *   协办单位：中国控烟与健康协会。
    *   项目名称：“控烟护肺·一扫双筛”肺癌、肺结核联合筛查“长征行”项目。
2.  **时间与地点**：
    *   启动时间：2026年8月29日下午。
    *   地点：江西省赣州市于都县（中央红军长征集结出发地），具体筛查点为长征源社区和思源社区。
3.  **活动内容与设备**：
    *   使用12米长常规移动诊疗车及8米长纯电小型诊疗车。
    *   设备搭载低剂量螺旋CT。
    *   筛查内容：同步进行肺癌、肺结核两种疾病的筛查，并可能发现肺结节、肺炎、冠脉钙化等胸部疾病。
    *   结果反馈方式：影像数据传回北京胸科医院，由医生集中阅片分析，一个多星期后通过手机发送结果。
4.  **当日成效**：
    *   累计完成免费胸部CT筛查568人次。
    *   北京胸科医院影像中心专家（包括医学影像中心主任侯代伦）在于都县人民医院影像科阅片室，带领5名于都本地医生进行CT影像查看、病例研讨和实操带教。
5.  **项目背景与规模**：
    *   项目启动背景：自2023年开展移动CT“一扫双筛”公益筛查以来，已覆盖19个省份、53个县市区、130个街乡镇，累计筛查超16.6万人次，筛出肺癌、肺结核各上千例。
    *   当前行动：“三年百万筛查行动”于2026年4月正式启动。
    *   “长征行”项目规划：沿红军长征足迹，走进江西等15个长征途经省份的30个重点县域，每个县域提供500个免费筛查名额。
