# Event Name

维多利亚州工会撤回对工党的竞选支持

## Event Overview

2026年11月4日，澳大利亚维多利亚州爆发了一场严重的政治危机。由于公共服务工会（Public Services Union, PSU）决定不支持维多利亚州工党（Victorian Labor Party）即将到来的竞选活动，导致州长丹尼尔·安德鲁斯（Daniel Andrews）领导的工党政府陷入危机边缘。

此前，工会曾因争取到超过1.5亿美元的资金用于减少政府内部的“昂贵顾问”支出而宣布支持竞选。然而，工会随后发现实际解雇的顾问人数远低于预期，因此撤销了支持决定。这一事件反映了工会成员对政府削减就业的不满，以及工党在中期支持下努力巩固选举前景所面临的挑战。

## Core Facts

1. **工会支持撤销**：维多利亚州公共服务工会（PSU）在最初表示支持工党竞选后，于周二（2026年11月3日）通知州长丹尼尔·安德鲁斯，决定不再支持该党。
2. **核心原因**：工会对政府未能大幅裁减内部顾问团队表示失望。尽管政府在2024年11月承诺解决这一问题，但工会发现仅裁减了75名顾问，而实际被削减的全职等效职位（FTEs）仅为约50个。
3. **预期落差**：工会原计划通过裁员节省1.84亿至1.91亿澳元（约1.15亿至1.19亿美元），但实际节省金额远低于预期，且裁员幅度不足。
4. **工会领导层的行动**：PSU主席约翰·帕帕多普洛斯（John Papadopoulos）表示，工会希望看到具体成果，并认为工会成员对政府不兑现承诺感到愤怒。他承认工会可能会继续施压，以争取更多利益。
5. **政府回应**：维多利亚州政府发言人强调，政府已解雇了大量顾问，并将节省的资金重新投入到医院和教师等公共服务领域。发言人称该党不会因个别工会的“政治姿态”而分心，并指出工会已从中获益。
6. **政治背景**：此次危机发生在工党准备中期选举之际。此前，包括消防员工会（FFCA）和公共工程和运输工会（PWU）在内的其他几个工会也未提供支持。然而，建筑工人联合会（AWU）和邮政局工会（PSA）仍表示支持。
