# Event Name

## Event Overview

2026年9月29日，《人民日报》刊发多版新闻报道，涵盖政治、经济、社会、文化等多个领域。当日正值烈士纪念日（9月30日）前夕，国务院常务会议召开，国庆招待会举行，同时发布了多项"十五五"开局之年的重要规划和政策解读。报道主题包括两岸融合发展、物流效率变革、世界技能大赛成绩、国防教育等。

## Core Facts

### 一、政治局势与重要会议

1. **国务院常务会议**（9月28日）
   - 总理李强主持会议，研究宏观政策发力提效、促进有效投资工作
   - 听取新污染物治理进展情况汇报
   - 审议通过《事业单位登记管理条例（草案）》
   - 强调加大宏观政策逆周期调节力度，推动"十五五"规划、"六张网"实施方案等重大工程项目开工

2. **国庆招待会**（9月28日）
   - 全国政协办公厅等六部门在北京人民大会堂联合举行
   - 庆祝中华人民共和国成立77周年
   - 中共中央政治局常委、全国政协主席王沪宁出席并致辞
   - 约750名港澳台侨各界代表出席

3. **王沪宁会见全国少数民族参观团**（9月28日）
   - 参观团成员共150人，以"团结奋进'十五五' 同心共筑中国梦"为主题
   - 强调"十五五"时期民族团结进步事业面临新的形势任务

4. **中华海外联谊会六届三次常务理事会**（9月28日）
   - 中共中央政治局委员、中央统战部部长李干杰出席并讲话

### 二、经济政策与发展规划

1. **《新型电池产业发展"十五五"规划》发布**（9月28日）
   - 工业和信息化部等7部门联合印发
   - 目标：到2030年，全固态电池初步实现规模化应用
   - 长寿命锂电池循环寿命达1.5万次，头部企业产品缺陷率达到PPB级

2. **科技保险发展数据**
   - 2026年前8月，科技保险为科技活动提供风险保障8.7万亿元
   - 同比增长66.9%

3. **物流效率变革成效**
   - 2025年社会物流总费用与GDP比率降至13.9%，首次低于14%
   - "6轴7廊8通道"国家综合立体交通网主骨架建成率超90%
   - 181个国家物流枢纽、105个国家骨干冷链物流基地已覆盖全国各省区市

4. **山东消费潜能释放**
   - 山东为北方首个GDP突破10万亿元的经济大省
   - 前8月中下旬，消费品以旧换新申请量超1430万件，带动销售额1157亿元
   - 曹县汉服相关企业超2800家，2025年销售额达130亿元

### 三、两岸融合发展

《中共中央 国务院关于支持福建探索海峡两岸融合发展新路建设两岸融合发展示范区的意见》印发3周年（2023年9月发布）：
- 福建发布5批74项促进闽台融合政策措施
- 组织实施206个闽台融合发展重点项目，总投资超1.3万亿元
- 今年前8月，"小三通"两岸旅客158.36万人次，同比增长25.34%
- 福建向金门供水量占金门自来水厂日常供水总量的87%
- 厦金国际机场将于2026年年底启用

### 四、国际赛事与人才建设

**第48届世界技能大赛**（9月27日闭幕于上海）：
- 中国代表团获41枚金牌、11枚银牌、4枚铜牌和6个优胜奖
- 连续5届位居金牌榜、团体总分世界第一
- 71名参赛选手平均年龄21岁
- 我国技能劳动者总量突破2.2亿人，高技能人才超7200万人

### 五、国防教育与精神文明建设

1. **"时代楷模"王戟先进事迹报告会**（9月28日）
   - 王戟为国防科技大学计算机学院研究员、博士生导师
   - 我国高可信软件技术领域主要开拓者，2026年7月被授予"时代楷模"称号
   - 中央军委副主席张升民会见报告团成员

2. **"全民国防教育月"活动**
   - 北部战区海军在青岛开展舰艇开放活动（9月19-22日）
   - 江西开展青少年国防素养大赛
   - 湖南汝城县组织新兵重走长征路

### 六、社会民生故事

1. **乡村教育坚守者**：湖北蕲春县青石实验小学盖天校区教师宋琳琳，坚守山村十五年，帮助留守儿童成长，2020年底被诊断乳腺癌晚期后仍坚持教学

2. **乡村产业创新**：浙江缙云南湖村通过拍摄"村剧"带动山茶油销售，村民增收100多万元

3. **智慧渔业发展**：湖南湘阴县引入"中国三星科技新农机项目"，来仪湖渔场亩均产量较10年前翻番
