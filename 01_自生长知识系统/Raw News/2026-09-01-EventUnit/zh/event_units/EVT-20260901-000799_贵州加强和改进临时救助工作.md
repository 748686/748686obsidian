# 贵州加强和改进临时救助工作

## Event Overview

2026年9月1日，据人民日报报道，贵州省民政厅、省财政厅日前联合印发《关于加强和改进临时救助工作的通知》。该通知旨在进一步加强和改进临时救助制度，充分发挥临时救助“兜底的再兜底”作用，并在贵州省全面开展急难事项“小额快救”制度。

## Core Facts

- **发布主体**：贵州省民政厅、贵州省财政厅。
- **政策文件**：《关于加强和改进临时救助工作的通知》。
- **核心措施**：推行急难事项“小额快救”。
- **适用情形（5种）**：
    1. 因突发重大疾病导致个人或家庭自身难以保障基本生活的；
    2. 因火灾等导致家庭财产重大损失，衣、食、住等基本生活得不到保障的；
    3. 因火灾、车祸、溺水、矿难等人身意外伤害导致严重受伤或死亡，且责任主体暂不明确、无赔偿能力或家庭自身难以保障基本生活的；
    4. 最低生活保障对象、特困人员、孤儿和事实无人抚养儿童、最低生活保障边缘家庭人口、刚性支出困难家庭人口等人员中基本生活出现严重困难的；
    5. 其他发生急难情况导致基本生活无法保障，需立即采取措施防止造成无法挽回损失或严重后果的。
- **简化程序**：乡镇人民政府（街道办事处）、县级民政部门受理后，确认材料属实及急难情形属实的，不再进行家庭经济状况核对和公示，直接登记并给予救助。
- **限额规定**：一般临时救助按常规额度执行；对于困难情形特别复杂、生活困难特别严重的，每户每次救助金额不超过5万元。
- **特殊机制**：针对困难情形复杂或救助金额已达上限仍不能缓解困难的情况，采取“一事一议”、个案会商等集体会商方式，综合运用各项救助帮扶政策。

- **行政效能提升**：通过取消家庭经济状况核对和公示环节，“小额快救”将显著缩短救助审批时间，提高响应速度。
- **兜底保障强化**：明确了5类急难情形和最高5万元的救助上限，有助于更精准地覆盖突发性生活困难群体，特别是低收入人口中的急难个案。
