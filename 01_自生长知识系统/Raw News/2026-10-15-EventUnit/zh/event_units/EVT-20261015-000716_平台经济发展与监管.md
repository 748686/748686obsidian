# Event Name

**平台经济发展与监管**

## Event Overview

本事件基于《人民日报》2026年10月15日理论版发表的署名文章《让平台经济更添百姓“烟火气”》。该文章为单一理论来源，系统阐述了我国平台经济的定义、作用、现存问题及未来治理方向。事件核心聚焦于在“十五五”规划背景下，如何坚持监管规范与促进发展并重，推动平台经济从“流量思维”向“民生温度”转型，实现平台企业、经营者、劳动者及消费者的共赢发展。

## Core Facts

### 1. 政策与战略背景
*   **顶层设计**：习近平总书记强调要“着眼长远、兼顾当前，补齐短板、强化弱项，营造创新环境，解决突出矛盾和问题，推动平台经济规范健康持续发展”。
*   **中央经济工作会议（2025年）**：明确“推动平台企业和平台内经营者、劳动者共赢发展”。
*   **“十五五”规划纲要**：提出“加强平台企业数据、算法、流量和规则监管，促进平台企业和平台内经营者、劳动者共赢发展”。
*   **政治局会议（7月30日）**：强调“推动平台经济规范健康发展”。

### 2. 平台经济的定位与作用
*   **定义**：以互联网平台为载体、大中小企业共生的新型经济形态，是数字经济的重要组成部分。
*   **技术支撑**：近年来在人工智能等数字技术支撑下快速发展。
*   **主要作用**：降低交易搜寻成本、打破交易时空阻隔；释放消费潜力、促进创新创业、推动产业升级、畅通国民经济循环、培育发展新动能。
*   **具体形态**：直播电商、即时零售等丰富了市场供给，方便群众生活，涌现出灵活就业岗位。

### 3. 存在的问题
*   部分平台受**流量思维**驱动，片面追求经营规模与经济效益。
*   需要解决如何使小微经营主体、新就业群体及广大消费者共享发展成果的问题。

### 4. 治理路径与发展方向
*   **有效监管**：
    *   坚持监管规范和促进发展并重，不搞“一刀切”。
    *   补齐监管短板，运用数字化监管工具，健全事前引导、事中动态监测、事后依法处置的全链条监管。
    *   深化反垄断和反不正当竞争执法，查处滥用市场支配地位行为。
    *   规范佣金标准、流量排序、交易规则，推动收费公开透明。
    *   压实平台主体责任，健全各方权益保障机制。
*   **开放生态**：
    *   构建包容开放的生态圈，加强平台内部及平台间合作。
    *   完善合规与质量管理体系，建立重大事项协商机制。
    *   引导平台降费让利，帮助中小企业减负增效。
    *   禁止利用数据、流量、技术等优势限制其他平台和应用独立运行。
*   **消费升级**：
    *   引导平台从“拼价格”、“内卷式竞争”转向“拼质量、拼创新”。
    *   开展品牌消费、品质消费促销活动，培育消费新增长点。
    *   助力优化医疗、社保、就业等公共服务，提升普惠化、便捷化、个性化水平。
