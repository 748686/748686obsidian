# 第二批零售业创新提升试点城市公布

## Event Overview

2026年9月4日，商务部等相关部门公布第二批全国零售业创新提升试点城市名单，共计32个城市入选。同日（9月5日），《人民日报》头版报道了该消息，将其列为当日要闻之一。与此同时，中央网信办、国家发展改革委、工业和信息化部、生态环境部、住房城乡建设部、农业农村部、商务部七部门联合印发《促进数字化绿色化协同转型发展实施方案（2026—2030年）》，旨在推进数字化与绿色化协同转型（“双化协同”）。

## Core Facts

1.  **事件主体**：商务部等4部门（根据Merge Reason）/ 商务部等相关部门（根据Article #489标题）。
2.  **事件内容**：公布第二批全国零售业创新提升试点城市名单。
3.  **数量**：32个城市。
4.  **时间**：
    *   名单公布时间：2026年9月4日。
    *   新闻报道时间：2026年9月5日。
5.  **相关背景政策**：2026年9月4日，七部门联合印发《促进数字化绿色化协同转型发展实施方案（2026—2030年）》，明确“十五五”时期双化协同的思路目标、重点任务和政策举措。
6.  **政策目标**：到2030年，人工智能深度赋能绿色低碳技术创新和产业发展，算力设施、5G基站等新兴领域用能效率大幅提升，重点领域数字化绿色化深入推进。
