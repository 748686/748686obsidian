# 我国合成世界上最长单原子直径“金属线”

## Event Overview

2026年9月5日，据《人民日报》第06版（科技·新知）报道，一项关于单金属原子链合成的科学突破被披露。报道标题为《我国合成世界上最长单原子直径“金属线”》，但引用的新闻来源为新华社伦敦电，内容实际描述的是英国南安普敦大学研究人员在室温下实现微型激光器自发同步的成果。该报道出现在北京高压科学研究中心相关研究成果发表于《科学》期刊的背景下，但提供的文本内容聚焦于光子计算领域的激光技术进展。

## Core Facts

根据提供的文章文本，核心事实如下：

1.  **研究机构**：英国南安普敦大学（University of Southampton）研究人员领衔的国际团队。
2.  **成果内容**：在室温下实现了多个微型激光器的自发同步，形成一种相干且可重构的光源。
3.  **技术原理**：研究团队在基于液晶和有机染料分子的光学微腔中生成彼此空间分离的微型激光器，使其在相同频率和相位下作为统一的相干光发射体工作，形成被称为“超模”的宏观集体状态。
4.  **对比优势**：
    *   此前此类激光控制现象大多在低于零下250摄氏度的专用半导体微腔中观测到，新平台可在室温下运行。
    *   具备电可调谐性：施加微小电压可重新定向液晶分子，调节光的传播方式和激光器运行模式。
    *   具备光学可重构性：微型激光器在同一器件中的相对位置可重新调整。
5.  **发表期刊**：相关研究论文已发表在英国《自然—通讯》（Nature Communications）杂志上。
6.  **潜在影响**：这项成果可能成为迈向成本更低、可重构且更易普及的光子计算技术的第一步。
