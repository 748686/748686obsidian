# Event Name

**EVT-20260905-000728：俄罗斯无人机袭击乌克兰情报总部及意大利政治背景综述**

## Event Overview

本事件单元综合了2026年9月4日至5日期间，关于俄乌冲突升级的军事行动报道以及意大利国内政治局势的相关资讯。核心焦点在于俄罗斯对乌克兰国家安全和情报总局（SBU）总部发动的无人机袭击，该事件被多方评估为冲突的重大升级。同时，关联信息涉及意大利政党“意大利力量党”（Forza Italia）因内部争议导致的议员流失及其领导层重组动态。

## Core Facts

*   **军事袭击事实**：俄罗斯于2026年9月4日对位于基辅的乌克兰国家安全局（SBU）总部实施了无人机袭击。
*   **袭击后果**：袭击造成至少2名乌克兰人丧生，另有3人受伤。乌军总参谋部确认，袭击导致该部门大部分文件档案损毁。
*   **国际反应与定性**：
    *   乌克兰总统泽连斯基谴责此次袭击为“恐怖主义行为”，并指出乌克兰无法再信任俄罗斯。
    *   美国国务院发言人表示，该袭击表明俄罗斯正在升级对乌克兰关键基础设施的攻击，构成重大升级。
    *   英国首相斯托纳（Starmer）向泽连斯基致信，表示英国坚定支持乌克兰。
*   **意大利政治动态**：
    *   意大利总理梅洛尼领导的联盟中，来自中右翼政党“意大利力量党”的至少3名议员因该党领导人西尔维奥·贝卢斯科尼支持俄罗斯总统普京立场而退出议会党团。
    *   前外交部长、意大利力量党主席安东尼奥·塔亚尼于2026年9月4日接任梅洛尼担任该党主席。
