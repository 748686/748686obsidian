# Event Name
第五届北斗规模应用国际峰会在湖南株洲举行

## Event Overview
2026年9月20日出版的《人民日报》报道，以“同世界·共北斗——赋能全球”为主题的第五届北斗规模应用国际峰会近日在湖南株洲举行。该峰会自2021年首届举办以来，北斗系统的市场辐射力、产业支撑力及国际影响力持续增强。报道重点阐述了北斗系统在性能服务提升、应用场景扩大以及国际合作广泛三个方面的发展成果，并指出北斗作为联合国认可的四大全球卫星导航系统之一，相关产品已出口至140余个国家和地区。

## Core Facts

**1. 峰会基本情况**
*   **时间**：2026年9月（具体日期报道未详述，只称“近日”）。
*   **地点**：湖南省株洲市。
*   **主题**：“同世界·共北斗——赋能全球”。
*   **届次**：第五届（首届于2021年举办）。

**2. 性能与服务提升**
*   **系统升级**：今年7月，北斗系统完成全部卫星在轨迭代升级。
*   **服务能力**：形成了全国实时厘米级位置服务能力，以及全球覆盖、快速收敛的高精度定位服务能力。
*   **接入保障**：具备10亿级终端接入和亿级大众用户、百万级行业用户稳定在线的保障能力。
    *   *来源声明*：中国卫星网络集团有限公司董事长苟坪。
*   **终端普及**：全球支持北斗短信功能的手机终端已超70款，开通用户规模超4.5亿。
    *   *来源声明*：中国时空信息集团有限公司董事长张弩。
*   **技术创新平台**：湖南建设了卫星导航技术重点实验室、测控与导航技术国家地方联合工程研究中心等国家级创新平台，组建了相关产学研用联合体，累计参与制定36项国家和行业标准。

**3. 应用场景与产业规模**
*   **产业数据**：“十四五”时期，北斗产业规模增幅超53%。截至2025年底，北斗导航产业覆盖交通、能源、城市建设、应急减灾等重点行业，并向低空经济、海洋经济、文体赛事等新领域拓展。
*   **民用应用案例**：
    *   **农业**：上海嘉定区外冈镇1万余亩高标准农田实现全流程智慧作业；集成新一代北斗定位终端的农机自动导航驾驶系统已应用至我国西部和北部地区农场。
        *   *来源声明*：上海司南导航技术股份有限公司企划负责人刘柏林。
    *   **出行导航**：今年正月初六，高德调用北斗日定位量达1万亿次，支撑日导航总里程达90亿公里。
        *   *来源声明*：阿里巴巴合伙人、高德董事长刘振飞。
*   **技术突破**：中国时空信息集团等单位牵头发布时空短报文新体制，推动短报文芯片成本降低70%，带动新体制芯片出货5000万片。
*   **区域集群**：株洲市集聚北斗企业188家，形成“星—箭—网—端—数”全产业链布局。2025年，株洲北斗时空信息产业集群规模达229.6亿元，近3年年均增速超30%。

**4. 国际合作与国际影响**
*   **出口范围**：北斗相关产品已出口至140余个国家和地区。
*   **国际评价**：柬埔寨王国邮电与通讯部部长兼数字政府委员会主席谢万迪表示，北斗提升了全球卫星定位导航授时服务的多样性、可用性及韧性。
*   **海外项目案例**：在沙特阿拉伯，中石化石油工程地球物理有限公司利用三维地震勘探高效采集技术帮助当地寻找油气资源。融合应用北斗系统后，施工精度和作业效率大幅提升，测量施工复测率减少85%。
    *   *来源声明*：中国石化北斗运营服务中心生产运行专家王仲文。
*   **发展趋势**：根据中国信息通信研究院编制的《北斗产业发展研究报告（2026年）》，北斗出海正从产品输出向“产品+方案+服务+生态”协同拓展升级。

**5. 未来规划**
*   面向“十五五”，我国将统筹天基导航增强、地基导航增强资源布局，推进北斗与低轨导航增强、5G/6G、惯性导航、激光雷达、视觉等多源时空信息融合，实现时空服务从室外到室内、从深海到深空全覆盖。
