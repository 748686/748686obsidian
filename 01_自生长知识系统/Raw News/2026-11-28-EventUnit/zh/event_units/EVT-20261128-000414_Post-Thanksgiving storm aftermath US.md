# Event Name

**美东感恩节风暴后的电力恢复滞后事件**

## Event Overview

2026年11月28日，美国（特别是东北部及宾夕法尼亚州部分地区）在经历干扰感恩节出行的暴风雨后，正处于灾后恢复阶段。核心情况是仍有数千用户处于停电状态，尽管电力公司正在努力恢复供电，但大规模停电仍未完全解决。

## Core Facts

1.  **事件起因**：风暴（被描述为“暴风雨”或“破坏性暴风雪”）袭击了美国东部，特别是东北部地区，并在感恩节期间造成了严重干扰。
2.  **当前状况**：截至2026年11月28日，仍有**数千用户**（"thousands of customers"）没有电力供应。
3.  **具体地点**：受灾地区包括新英格兰（New England）、纽约州（New York）、新泽西州（New Jersey）以及宾夕法尼亚州（Pennsylvania）的部分地区。
4.  **影响程度**：
    *   风暴导致数百万人一度失去电力。
    *   部分断电情况持续了数天（"days-long power outages"）。
    *    宾州电力公司（PPL）表示，虽然仍有数千客户受影响，但大多数之前停电的用户已恢复供电。
5.  **基础设施状况**：风灾导致树木倒塌并砸在电线上，这是造成持续停电的主要原因之一，使得恢复工作面临挑战。
