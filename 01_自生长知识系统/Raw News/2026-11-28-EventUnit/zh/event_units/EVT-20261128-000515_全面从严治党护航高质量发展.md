## Event Name
全面从严治党护航高质量发展：从河长制看河长治（基于《人民日报》2026年11月28日第4版报道）

## Event Overview
2026年11月28日，《人民日报》刊发署名王浩、邓剑洋的评论员文章《从河长制看河长治》，纪念中共中央办公厅、国务院办公厅印发《关于全面推行河长制的意见》10周年。文章指出，2016年11月28日是河长制意见印发的十周年节点，十年来中国通过以党政领导负责制为核心的河湖保护治理责任体系，实现了从“九龙治水”到“党政同责”的转变。报道强调，全面推行河长制是习近平总书记“看得最多、想得最深”的治国理政实践之一，旨在通过生态文明建设推动高质量发展，践行“绿水青山就是金山银山”理念，并为基层减负、提升治理效能提供制度保障。

## Core Facts
1. **时间节点**：2016年11月28日，中共中央办公厅、国务院办公厅印发《关于全面推行河长制的意见》；2018年6月，全国31个省份全面建立河长制。
2. **核心制度**：建立省市县乡四级河长体系，以党政领导负责制为核心，破解“条块分割、多头治污”难题。
3. **治理成效**：
   - 全国地表水Ⅰ—Ⅲ类断面比例从2016年的67.8%提升至2025年的91.4%。
   - 2022年以来，全国重要江河湖泊生态流量达标率稳定在90%以上。
   - 长江沿线累计拆除非法码头1361座，推动近万家化工企业完成关停、搬迁、改造或转型。
   - 累计整治乱占、乱采、乱堆、乱建“四乱”问题31.5万个。
4. **典型案例**：
   - **浙江长兴县车渚港**：从“龙须沟”到村民通过杨梅产业致富，体现“好环境真的能当饭吃”。
   - **江西九江**：2513名河湖长5年累计巡河近45万次，推动解决涉河湖问题4000余个。
   - **内蒙古黄旗海/岱海/乌梁素海**：通过“山水林田湖草沙”系统治理，重现生态生机。
   - **吉林查干湖**：坚持“年年有鱼”，生态与旅游相得益彰。
   - **安徽-浙江新安江**：历经三轮生态补偿机制试点，形成“新安江模式”。
5. **战略定位**：河长制纳入中央生态环境保护督察和落实水资源刚性约束制度考核，成为生态文明体制的重要组成部分。
