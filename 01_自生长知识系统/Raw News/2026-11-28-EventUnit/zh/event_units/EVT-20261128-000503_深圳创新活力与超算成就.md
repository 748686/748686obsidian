# 深圳创新活力与超算成就

## Event Overview

2026年11月28日，《人民日报》第01版刊发题为《“创新是深圳的活力所在”》的长篇通讯报道。该报道以深圳APEC会议期间习近平总书记对创新发展的关注为切入点，系统梳理了深圳从“世界工厂”向“创新之城”转型的历史脉络与现实成就。

报道核心聚焦于三大主题：
1. **源头创新**：以国家超级计算深圳中心“灵晟”超算系统蝉联世界第一为标志性事件，阐述深圳在基础研究领域的突破。
2. **主体创新**：强调企业在创新中的主导地位，以及“工业上楼”等模式促成的产学研深度融合。
3. **集群创新**：展示深圳先进制造业与现代服务业比翼齐飞，形成集群式创新的区域发展格局。

## Core Facts

*   **时间背景**：报道发布于2026年11月28日；回顾的关键时间节点包括1987年、1993年、1995年及2020年。
*   **标志性事件**：当地时间11月17日，全球超算TOP500榜单在美国芝加哥发布，国家超级计算深圳中心“灵晟”超算系统蝉联世界第一。
*   **核心论断**：
    *   “创新是深圳的活力所在。”
    *   深圳已完成从出口加工到自主研发、从“世界工厂”到创新之城的转变。
    *   深圳已成为中国集群式创新的前沿。
*   **数据指标**：
    *   深圳每年国际专利申请量近2万件。
    *   全社会研发投入强度达7.1%，位于全国城市前列。
    *   国家高新技术企业突破2.6万家，密度居全国第一。
    *   建成各类创新平台载体超4000家。
    *   90%以上的研发机构设立在企业、90%以上的研发人员集中在企业、90%以上的职务发明专利出自企业。
    *   今年前三季度，深圳高技术制造业增加值增长11.6%，先进制造业增加值增长11.9%。
    *   今年前三季度，深圳3D打印设备产量增长77.8%，工业机器人产量增长44.1%，锂离子电池产量增长38.5%。
*   **政策沿革**：
    *   1987年：发布“18号文”，成为中国首份民营科技企业“准生证”。
    *   1993年：停止登记“三来一补”企业，主动放弃加工贸易红利。
    *   1995年：明确以高新技术产业为先导。
    *   制度建设：出台《深圳经济特区科技创新条例》，在全国率先以立法形式保障基础研究投入；深圳市自然科学基金委员会揭牌成立。
*   **典型成果与案例**：
    *   **超算领域**：“灵晟”超算系统，实现自主可控软硬件体系。
    *   **机器人领域**：南方科技大学变胞机器人、南山智造红花岭基地（速腾聚创激光雷达，每8秒下线一件）、“机器人谷”产业带（200多家制造企业）。
    *   **生物医药**：华大集团多模态片上脑机交互系统；中科院深圳先进技术研究院人工光合作用突破。
    *   **材料科学**：深圳材料基因组大科学装置中子谱仪平台，两年完成1500多个样品测试。
    *   **智能网联汽车**：坪山区湾区智联试验场，2025年规上工业产值达1194亿元，同比增长23.2%。
    *   **数字制造**：光明区联想南方智能制造基地，生产效率提升20%，成本降低10%。
*   **企业主体**：华为、腾讯、比亚迪、大疆、荣耀、优必选、速腾聚创等。
*   **创新集群排名**：“深圳—香港—广州”创新集群蝉联全球百强创新集群榜首（截至今年9月）。
