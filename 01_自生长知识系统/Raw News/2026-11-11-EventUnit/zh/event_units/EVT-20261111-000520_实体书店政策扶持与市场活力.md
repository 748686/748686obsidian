# EVT-20261111-000520 实体书店政策扶持与市场活力

## Event Overview

2026年11月10日，中央宣传部、中央社会工作部、教育部、财政部、住房城乡建设部、商务部、文化和旅游部、国家文物局联合印发《中共中央宣传部等关于支持实体书店服务全民阅读的通知》。同日，《人民日报》刊发评论员文章《支持实体书店服务全民阅读》及长篇通讯《让实体书店焕发新活力》，系统阐述政策内容与各地实践探索，反映实体书店在全民阅读战略下的政策支持与市场活力。

## Core Facts

### 政策发布
- **时间**：2026年11月10日
- **文件**：《中共中央宣传部等关于支持实体书店服务全民阅读的通知》
- **发文单位**：中央宣传部、中央社会工作部、教育部、财政部、住房城乡建设部、商务部、文化和旅游部、国家文物局（共八个部门）
- **政策依据**：贯彻《全民阅读促进条例》，落实2026年《政府工作报告》任务
- **信息来源**：ARTICLE #373（人民日报，记者李卓尔）

### 政策核心内容
根据ARTICLE #373，通知提出以下四个方面部署：

1. **提升书店供给质量**
   - 实施"千名店长"成长培训计划
   - 增强书店选品能力
   - 建立"书店主讲人"公共数据库
   - 推动新华书店更新门店网点
   - 鼓励民营书店差异化发展
   - 依托书店开展阅读推广志愿服务活动

2. **培育特色阅读空间**
   - 打造一批地标书店、特色书店、主题书店和"小而美"空间
   - 融入城市更新行动
   - 纳入完整社区和城市一刻钟便民生活圈

3. **支持书店参与公共文化服务**
   - 承担基层全民阅读设施运营管理、图书馆馆配服务和阅读活动
   - 推动书店与公共文化机构深度融合
   - 结合实际纳入县级公共图书馆总分馆体系和新型公共文化空间扶持范围
   - 赋能书香校园建设，鼓励书店建设校外阅读指导课堂和阅读实践基地
   - 扶持校园书店建设

4. **加强财政扶持引导**
   - 地方财政支持书店平等参与承接公共阅读服务等政府购买服务项目
   - 中央财政体现绩效奖励
   - 各地通过发放惠民购书券、全民阅读消费券等方式带动图书阅读和销售
   - 鼓励国有企事业单位减免租金等费用
   - 优化书店多元经营证照办理流程
   - 推进线上线下对接融合
   - 推广书店地图导航
   - 持续规范图书网络发行秩序

### 市场实践案例
根据ARTICLE #374，政策落地过程中各地涌现多种创新模式：

**供给质量提升方面：**
- 江西南昌市青苑书店：每年从20余万种新书中精选5%上架，与中华书局、三联书店合作，聚焦经典文史、传统文化；依托销售数据和读者反馈研判需求
- 北京中国书店隆福寺店：闭店多年后于2026年2月重新开业，旧书区经营中华书局1979年版《白居易集》等古籍，开办"古籍之为艺术"展

**特色空间培育方面：**
- 上海杨浦区五角场街道大学路：700米长的街区周末客流超10万人次；复旦旧书店2022年因街区改造搬迁至此；2025年举办活动近900场，客流超1200万人次，销售额超2亿元；街道简化活动报备流程，允许门店外摆，支持销售咖啡茶饮
- 江苏苏州古吴轩书店："文保+书店"模式，背靠章太炎故居，开展"章园夜校"，开设古籍修复、昆曲等60多门课程，吸引2000多人次参加
- 甘肃兰州："你借书·我买单"模式，读者凭图书馆读者证在西北书城借阅图书
- 湖北：建成高校书店36家
- 浙江德清县："农家书屋+新华书店"模式，乡镇出场地、新华书店管运营，书籍月月上新、城乡通借通还
- 河南开封谜芸馆：从卖书转向集"阅读、社交、版权"要素于一体的复合经营

**成本降低方面：**
- 贵州：2026年7月启动出版物促消费活动，云闪付购书立减优惠，500万元促销经费带动销售超1800万元、交易超10万笔、惠及读者超12万人次
- 中粮大悦城：在25座商场给予35家书店场租优惠；2026年7月北京朝阳大悦城3700平方米中信书店开业，首周客流超10万人次，销售额超50万元，读者平均停留时长80分钟
- 浙江：政府购买服务扶持书店开展阅读推广，省级投入超1000万元，扶持书店300余家
- 山东济南三叠纪·TRIBE书店："0租金+营收分成"合作模式，月均营收约30万元
- 四川眉山市彭山区：营业执照、出版物经营许可等事项并联办理

**线上流量利用方面：**
- 高德地图：2026年7月联合北京、上海、广州等9座城市推出"城市书香地图"，标注400余家实体书店；后延伸至川渝云贵

**政策背景：**
- "支持实体书店发展"首次写入2026年《政府工作报告》
- 《全民阅读促进条例》规定县级以上人民政府采取政策措施支持实体书店发展

## Event Conclusion

2026年11月10日，中宣部等八部门联合印发《关于支持实体书店服务全民阅读的通知》，标志着实体书店支持政策进入系统化推进阶段。政策从供给质量提升、特色空间培育、公共文化服务参与、财政扶持引导四个维度构建支持框架，首次将"支持实体书店发展"写入《政府工作报告》，显示政策优先级提升。

同日，《人民日报》刊发深度报道，呈现上海、江苏、甘肃、湖北、浙江、贵州、山东、四川等地已涌现的多元实践案例，包括街区阅读空间营造、文保融合、馆店联动、高校书店布局、消费券促消费、零租金分成等模式。部分案例已产生可量化的积极效果。

当前，政策刚发布不久，全国性实施进度、中央财政具体支持规模、行业整体经营数据等关键信息尚未披露，需持续关注后续进展。
