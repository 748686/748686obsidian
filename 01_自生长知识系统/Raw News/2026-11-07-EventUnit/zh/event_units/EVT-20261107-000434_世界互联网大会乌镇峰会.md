# Event Name
2026年世界互联网大会乌镇峰会

## Event Overview
2026年11月2日至5日，世界互联网大会乌镇峰会在浙江嘉兴乌镇举行。本次峰会以“开源开放 共建共享——携手构建网络空间命运共同体”为主题，来自138个国家和地区的约1800名嘉宾参会。会议聚焦人工智能发展与数字技术未来趋势，旨在通过数字合作推动构建网络空间命运共同体迈向新阶段。

## Core Facts
*   **时间与地点**：2026年11月2日至5日，浙江嘉兴乌镇。
*   **参会规模**：来自138个国家和地区的约1800名嘉宾。
*   **永久主题**：携手构建网络空间命运共同体。
*   **核心议题**：人工智能发展、开源开放、网络空间治理、数字技术国际合作。
*   **重要发布**：
    1.  **“网络空间命运共同体共建计划”**：在世界互联网大会主论坛上发布，由常务副秘书长梁昊介绍。该计划重点支持前沿研究、会议活动、出版传播3类项目。
    2.  **2026年“携手构建网络空间命运共同体”精品案例**：于11月2日发布展示。
    3.  **《CPOPwave中国潮流IP出海研究报告》**：在“文化新三样·CPOPwave中国潮流IP全球对话”活动中发布，梳理了《哪吒之魔童闹海》《燕云十六声》《藏海传》等“十大优秀出海案例”及长红IP《原神》。
    4.  **《前沿人工智能安全与治理2026：风险认知与协同治理》报告**：由世界互联网大会人工智能专业委员会主任委员曾毅发布，梳理AI风险图景并识别治理缺口。
*   **博览会数据**：“互联网之光”博览会以“智能互联、智见未来”为主题，吸引671家中外企业和机构线上线下联动参与。
*   **科技奖项**：2026年世界互联网大会领先科技奖收到430余项参选成果，涉及脑机接口、具身智能、量子计算、空间信息传输、高性能芯片等领域。
