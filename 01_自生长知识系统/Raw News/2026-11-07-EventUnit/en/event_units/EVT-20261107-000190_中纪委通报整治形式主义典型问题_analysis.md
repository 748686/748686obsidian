## Event Analysis

### 标题：中央纪委国家监委通报三起整治形式主义为基层减负典型问题

### 作者：中共中央纪律检查委员会 / 中央纪委国家监委

### 标签
政治、党建、反腐败、形式主义、基层减负、财政纪律、统计造假、国有企业改革

### 一句话总结
2026年11月6日，中央整治形式主义为基层减负专项工作机制办公室会同中央纪委办公厅公开通报河北沧州、内蒙古包头、中国邮政黑龙江分公司三起典型问题，重点纠治统计造假、骗取国债资金及国企业绩注水等行为，释放严纠形式主义、强化政治监督的强烈信号。

### 文章内容摘要

**一、 事件背景与核心结论**
2026年11月6日，中央整治形式主义为基层减负专项工作机制办公室会同中央纪委办公厅，对三起违反中央八项规定精神、加重基层负担的典型问题进行了公开通报。通报指出，上述问题暴露出部分地区和部门在贯彻落实党中央决策部署上存在严重偏差，主要表现为统计造假、项目资金骗补以及国有企业考核指标脱离实际导致的系统性数据注水。此次通报旨在通过典型案例警示全党，推动“六个纠治”落地见效，切实为基层减负，确保经济社会发展数据真实可靠。

**二、 三大典型问题详解（归纳法展开）**

通报指出的三起问题分别涉及地方政府统计造假、违规套取财政资金、国有企业经营数据失真，具体表现如下：

1.  **河北沧州：统计造假与监管缺位**
    *   **问题根源**：盲目追求高增长目标，层层加码。
    *   **具体行为**：肃宁县为完成招商引资任务，允许企业以极低注册资本（如1000元）和极小股权比例（如0.02%）虚增省外项目投资；青县指导电商平台篡改统计数据和流水凭证，网络销售额虚增超3倍。
    *   **监管失职**：市级部门对指标完成情况“只考不核”，缺乏实质性核查机制。

2.  **内蒙古包头：虚假包装项目骗取国债资金**
    *   **问题根源**：项目审批审核流于形式，监管责任缺失。
    *   **具体行为**：包立伦区将已完工验收的燃气管网项目，伪造可行性研究、初步设计等材料，包装成新建项目申报2024年城市地下管网改造超长期特别国债资金。
    *   **资金损失风险**：违规获批资金3908万元，并在未核实监理材料真实性的情况下，违规拨付2200万元。

3.  **中国邮政黑龙江分公司：业绩考核扭曲导致收入注水**
    *   **问题根源**：重规模轻效益，考核指标设置不科学。
    *   **具体行为**：为完成营收目标，寄递业务采取“低收高记”手段虚增收入8772万元；快递业务将商品销售收入违规计入快递服务收入，虚增收入1900余万元。
    *   **系统性风险**：压力层层传导至基层网点，导致全员参与的数据造假。

**三、 官方定性与整改要求**

通报对这三起问题进行了深入剖析，并提出了明确的整改要求：

*   **性质认定**：
    *   一是贯彻党中央防惩统计造假决策部署不力，把“抓发展”简单等同于“抓数据”；
    *   二是项目审批监管失效，变相骗取财政资金，造成国有资产流失风险；
    *   三是国企考核导向偏差，引发系统性数据失真。

*   **工作要求**：
    *   各级党委（党组）要深入学习党的二十届五中全会精神，承担整治形式主义的主体责任，开展自查自纠；
    *   中央和国家机关要发挥“风向标”作用，刀刃向内，查摆本系统问题；
    *   各级专项工作机制办公室要聚焦重点领域，深化“六个纠治”，强化问题整改闭环管理。

2.  **典型案例详述**
    *   **案例一：河北沧州市**
        *   肃宁县：招商引资数据造假（空壳股东、虚假投资）
        *   青县：电商数据统计造假（篡改流水、虚增销售额）
        *   市局问题：考核与核查脱节（只考不核）
    *   **案例二：内蒙古包头市包立伦区**
        *   违规行为：已完工项目伪装成新建项目申报国债资金
        *   审批漏洞：区、市两级审核不严
        *   资金后果：违规获批3908万元，已违规拨付2200万元
    *   **案例三：中国邮政集团有限公司黑龙江省分公司**
        *   考核导向：片面追求规模，忽视效益
        *   寄递业务：虚构收入8772万元
        *   快递业务：违规列支收入1900余万元

3.  **问题根源分析**
    *   政治站位不高，贯彻落实党中央决策部署打折扣
    *   政绩观错位，急功近利，弄虚作假
    *   监管机制缺失，审批审核流于形式
    *   考核体系不科学，导致基层被迫造假

4.  **整改要求与工作部署**
    *   各级党委（党组）：履行主体责任，开展举一反三自查自纠
    *   中央和国家机关：发挥示范引领作用，查摆系统内问题
    *   各级专项工作机制办公室：深化“六个纠治”，加强重点领域监督
    *   强化结果运用：将整治形式主义为基层减负工作纳入考核评价体系

5.  **结语**
    *   强调实事求是的工作作风
    *   呼吁各地区各部门引以为戒，坚决防止形式主义反弹回潮
