# 748686 知识系统数据异常处理机制

## 核心定义

系统通过 Event Analysis Engine 识别事件与来源的主题错位及来源可信度缺失，防止错误事实污染知识库主干。

## 新增事实

- 当事件标题指向'习'、'金砖峰会'、'AI愿景'而来源指向'欧盟'、'电动卡车'时，系统判定为主题严重错位。
- 当来源状态标记为 horizon_summary_only 且明确标注'未找到可信原文'、'URL缺失'时，该来源被视为不可靠。
- 在缺乏匹配主题的可靠来源时，事件应标记为 data_mismatch 或 investigation_required，并暂缓进入知识库主干。
- 单一来源且主题不符时，无法执行 MECE 原则下的多源交叉验证。
