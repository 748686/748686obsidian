# Kleptocracy Analysis Framework (盗窃统治分析框架)

## 核心定义

基于王公与窃贼框架的治理与犯罪案例研究集合，包括后苏联俄罗斯、哥伦比亚毒品战争和意大利黑手党国家。

## 新增事实

- 后苏联俄罗斯(1990s-2000s)：前克格勃官员和共产党精英与有组织犯罪集团合并形成寡头结构
- Boris Berezovsky和Roman Abramovich是王公-窃贼混合体的典型例子
- 哥伦比亚毒品战争(1980s-2000s)：麦德林和卡利卡特尔与国家内部元素共存
- Patriot Union大屠杀和各种准军事组织联系揭示了国家力量与毒贩的合作
- 意大利黑手党国家(20世纪晚期)：黑手党在国家内部运作，影响选举、公共合同和执法
- Corleonesi派系在Salvatore Riina领导下展示了犯罪等级如何模仿国家官僚机构
