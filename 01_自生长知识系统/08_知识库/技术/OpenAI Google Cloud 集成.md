# OpenAI Google Cloud 集成

## 核心定义

OpenAI模型正式接入Google Cloud平台（Gemini Model Garden），企业客户可利用现有云承诺额度支付费用。这打破了此前微软Azure的独家云伙伴格局，标志着AI多云生态格局初现。
