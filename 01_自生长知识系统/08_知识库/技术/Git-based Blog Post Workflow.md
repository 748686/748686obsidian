# Git-based Blog Post Workflow

## 核心定义

基于Git版本控制的工作流，将个人历史内容（博客、社交媒体、代码）归档至统一存储库，作为AI辅助知识回顾的基础设施。

## 新增事实

- 该方法用于聚合分散在不同平台（WordPress, Medium, LessWrong, GitHub等）的历史内容。
