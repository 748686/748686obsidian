# 748686 自生长知识系统数据摄取验证机制

## 核心定义

748686 系统通过多层验证（第一层合并判断、第二层多来源综合）识别数据完整性错误。当来源文章状态为'未解决'或仅为'Horizon 摘要'时，系统标记为无法确证事实，并建议重新摄取。

## 新增事实

- 系统规定'Horizon 摘要'不具备原始文本的事实确证能力，不能作为发布确凿事实的依据
- 当多源交叉验证结果为'零匹配'时，系统应标记 Event ID 进行重新数据摄取，而非强行推断
