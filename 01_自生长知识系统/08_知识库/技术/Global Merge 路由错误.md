# Global Merge 路由错误

## 核心定义

知识系统在聚合阶段可能因关键词误匹配（如都涉及‘美国’、‘政治’）将不相关的新闻归并到同一 Event Unit。

## 新增事实

- Global Merge 阶段可能发生源内容不相关性错误。
- 路由算法需优化语义相关性以避免将无关新闻聚类。
