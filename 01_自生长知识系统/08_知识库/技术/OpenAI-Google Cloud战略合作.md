# OpenAI-Google Cloud战略合作

## 核心知识

2026年10月21日，OpenAI宣布其前沿模型及Codex代理工作流将集成至Google Cloud的Gemini Model Garden。这标志着OpenAI从微软Azure独家伙伴转向多云战略。企业客户可通过Google Cloud Marketplace访问，并可用现有云承诺额度支付。Microsoft仍保持OpenAI的'主要云合作伙伴'地位。同时，OpenAI推出'Patch the Planet'平台协调开源漏洞响应，ChatGPT Ads注册用户超10万并扩展至26国。

## 知识更新｜2026-10-22

- OpenAI模型正式接入Google Cloud Gemini Model Garden，支持Codex代理工作流
- 企业可用现有Cloud支出承诺额度支付OpenAI费用
- OpenAI推出'Patch the Planet'平台用于协调全球开源漏洞响应
- ChatGPT Ads扩展至26个新国家，注册用户突破10万
