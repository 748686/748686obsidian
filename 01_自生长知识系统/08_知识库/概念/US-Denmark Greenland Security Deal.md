# US-Denmark Greenland Security Deal

## 核心定义

2026年9月20日美国与丹麦达成的安全协议，背景为特朗普此前的吞并威胁。协议允许美国扩大在格陵兰的军事存在，但丹麦/格陵兰保留主权。

## 新增事实

- 协议背景是特朗普威胁‘接管’格陵兰
- 协议内容包含扩大美军在格陵兰的存在
- 丹麦和格陵兰的主权在协议中得到保留
- 北约对此表示欢迎（来源未完全验证）
