# 多云战略 (Multi-cloud Strategy)

## 核心定义

OpenAI 采取的双轨并行多云策略，在保持微软为主要云合作伙伴的同时，正式接入 Google Cloud，以降低客户锁定风险并扩展市场覆盖。

## 新增事实

- OpenAI 已正式进入多云战略第二阶段，同时服务于 Microsoft Azure 和 Google Cloud 生态。
- 该策略允许企业客户在受治理环境中通过 Google Cloud Marketplace 访问顶级 AI 模型。
