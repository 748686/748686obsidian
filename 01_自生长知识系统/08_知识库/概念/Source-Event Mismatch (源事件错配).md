# Source-Event Mismatch (源事件错配)

## 核心定义

指事件单元的主题与其关联的新闻源内容不一致的情况，常见于多源综合或聚类过程中，导致无法对核心议题进行有效分析。

## 新增事实

- EVT-20261003-000148是典型的源事件错配案例：事件标题涉及美日贸易与日元汇率，但实际获取的仅有一篇关于Tokai Kisen航运监管的文章。
- 此类错配会导致事件无法进行实质性综合分析，因为核心议题缺乏直接新闻源支持。
