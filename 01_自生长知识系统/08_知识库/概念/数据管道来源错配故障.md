# 数据管道来源错配故障

## 核心定义

指知识系统在处理新闻事件时，错误地将不相关的来源（如体育报道）关联至不相关的主题（如政治贸易），导致事件无法验证并产生“幽灵事件”风险的系统性故障。

## 新增事实

- EVT-20260913-000080 中，关于美加贸易战的假设被错误关联至一篇美国女足世界杯的体育报道。
- 此类故障导致来源状态标记为 'unresolved' 或 'horizon_summary_only'，缺乏有效 URL 和正文支持。
- 日报显示 2026-09-13 的 Batch 3 至 43 中约 80-90% 的事件存在此类映射错误。
