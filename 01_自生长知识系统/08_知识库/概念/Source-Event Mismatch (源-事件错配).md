# Source-Event Mismatch (源-事件错配)

## 核心定义

一种数据质量问题，指事件分析系统中的源文章与所描述的事件主题严重不匹配，导致核心主张缺乏有效证据支持。

## 新增事实

- 2026年10月3日，748686自生长知识系统出现系统性Source-Event Mismatch故障，超过50%的事件存在源文章与主题错配或原文缺失问题。
