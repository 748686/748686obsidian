# OpenAI Terminal X金融垂直领域智能体

## 核心知识

OpenAI于2026年10月21日发布Terminal X，这是一款针对金融垂直领域的评估智能体，集成了GPT-6.1模型。其实证数据显示，在匹配资深投资者判断方面的准确率达到88.6%，标志着大模型向高精度企业级应用迈出了重要一步。ChatGPT Work在加盟商现金对账场景中能将时间减少94%。
