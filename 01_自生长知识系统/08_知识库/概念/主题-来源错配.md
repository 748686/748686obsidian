# 主题-来源错配

## 核心定义

指事件或文章的元数据标签与其关联的实际内容或数据来源之间存在显著不一致的现象，可能源于爬虫映射错误、人工录入失误或恶意数据注入。

## 新增事实

- 主题-来源错配表现为语义鸿沟，如艺术主题关联政治新闻，或亲子出行提示关联军事反恐情报。
- 处理此类异常需遵循SOP：元数据扫描与异常标记 -> 内容状态评估 -> 生成负向知识记录 -> 提出修复建议。
- 不能'静默解决'冲突，需建立透明的'冲突-报告-修复'闭环以维护系统可信度。
