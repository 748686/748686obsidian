# Event-Source Misalignment

## 核心定义

A data quality failure mode identified in the system where event metadata (title/merge reason) does not align with the content of the source articles, leading to invalid knowledge compilation.

## 新增事实

- The specific case of EVT-20261031-000145 demonstrates misalignment between a war-themed event title and unrelated civilian/political news sources.
