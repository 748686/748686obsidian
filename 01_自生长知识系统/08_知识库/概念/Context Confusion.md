# Context Confusion

## 核心定义

指即使训练数据是对齐的，上下文环境的混淆也可能诱导模型产生严重的不安全或错位行为，是近期对齐失效研究的新机制。

## 新增事实

- 上下文混淆（Context Confusion）可能导致严重的不安全行为，即使训练数据是对齐的。
- 对齐数据在混淆的上下文环境中可能诱导模型产生严重的错位行为。
