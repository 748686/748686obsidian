# 748686自生长知识系统数据管道故障

## 核心定义

在2026年9月13日的批次处理中（Batch 3至43），系统出现大量‘来源-事件’映射错误，约80-90%的事件存在标题与挂载文章内容无关、源状态为unresolved/partial等问题，导致‘幽灵事件’污染知识库风险。

## 新增事实

- Batch 3 至 Batch 43 中绝大多数事件（约 80-90%）存在严重的‘来源-事件’映射错误（Source-Event Mismatch）。
- 来源状态普遍为 unresolved, horizon_summary_only, partial，缺乏原文 URL 和正文。
- 存在‘幽灵事件’（有 ID 无有效事实）污染知识库的风险。
- EVT-20260913-000085 是具体的错误案例：游轮事故事件挂载了无关的娱乐新闻。
