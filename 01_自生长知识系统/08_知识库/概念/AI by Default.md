# AI by Default

## 核心定义

指AI系统以被动、默认设置形式集成到现有流程中，无需用户主动配置或明确知晓即可运行的现象。

## 新增事实

- AI系统集成常以未配置默认状态运行，用户可能不知情
- 该现象挑战传统人机协作中的知情同意原则
