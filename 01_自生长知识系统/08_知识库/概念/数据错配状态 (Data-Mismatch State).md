# 数据错配状态 (Data-Mismatch State)

## 核心定义

指新闻事件标题与源文章内容存在根本性冲突，导致无法确认事件事实真实性的系统状态。在Horizon日报聚合流程中，当源文章缺失原始URL且被错误归类时可能出现此状态。

## 新增事实

- 数据错配状态发生在事件标题与源文章内容严重不匹配时
- 该状态会导致实质性事实陈述无法成立
