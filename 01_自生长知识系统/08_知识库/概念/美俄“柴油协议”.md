# 美俄“柴油协议”

## 核心定义

2026年10月提及的美俄双边协议，被乌克兰总统泽连斯基批评损害乌克兰利益，反映跨大西洋联盟在援乌问题上的裂痕。

- 该协议被乌克兰总统泽连斯基公开批评损害乌克兰利益。
