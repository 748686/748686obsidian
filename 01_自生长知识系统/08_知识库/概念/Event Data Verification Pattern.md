# Event Data Verification Pattern

## 核心定义

在自生长知识系统中，当新闻源内容与事件主题存在严重错配（如将旅游文章关联至教育政策事件）且源内容缺失（partial status）时，该事件不具备长期知识价值，仅作为数据质量验证案例保留。

## 新增事实

- 源材料关联失效是事件数据质量低下的关键指标。
