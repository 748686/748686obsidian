# Source-Event Mismatch (源-事件不匹配)

## 核心定义

系统数据管道中的潜在缺陷类型，指新闻事件分类与来源内容严重不符的情况。

## 新增事实

- 当唯一来源与事件分类完全无关时，综合状态判定为'不完整'。
