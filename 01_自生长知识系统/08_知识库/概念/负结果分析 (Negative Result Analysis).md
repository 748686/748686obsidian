# 负结果分析 (Negative Result Analysis)

## 核心定义

在AI辅助信息聚合中，证明某事件当前无法成立（因数据断层或错误归因）本身是一种重要的知识产出，具有系统质量控制价值。

## 新增事实

- 当源数据缺失或元数据错误时，AI可能产生幻觉或错误关联，导致事件结论不可靠。
- 源头数据的完整性比聚合算法更重要。
