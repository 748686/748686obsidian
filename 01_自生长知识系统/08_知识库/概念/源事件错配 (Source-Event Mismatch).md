# 源事件错配 (Source-Event Mismatch)

## 核心定义

指自动化新闻聚合系统中，源文章内容与分配的事件主题完全不符的数据质量故障模式。本案例中英国零售主题被错误关联至中国政治和历史纪念新闻。

## 新增事实

- EVT-20261023-000072 是已记录的源事件错配案例，预期主题为英国零售，实际内容为梁振英活动和长征纪念邮票。
